# Tool Spec：western_geomancy_interpretation_planner

## 目的

把西洋土占盾形盘转成低风险解释计划，保留起盘来源、图形位置、缺失字段和现实验证步骤。

## 输入

同 `western_geomancy_chart_recorder`。

## 输出

- `figure_plans`
- `interpretation_plan`
- `limits`
- `next_steps`

## 解释顺序

1. 声明西洋土占只作象征反思。
2. 标注起盘来源、生成方式和盘面缺失。
3. 从母亲图、见证者和裁判者整理象征层。
4. 输出 1-3 个可验证、可撤回、非高风险小动作。
5. 若出现专业替代、财务赌博、灵异恐惧、第三方窥探、操控或反复依赖，暂停流程。
