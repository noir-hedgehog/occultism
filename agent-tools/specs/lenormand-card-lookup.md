# lenormand_card_lookup

查询 36 张雷诺曼牌的基础象征、关键词、解释提示和禁止用途。

## 输入

- `query`：牌名、英文名、序号或常见中文别名。
- `focus`：咨询焦点，例如 `project_reflection`、`relationship_boundary`。

## 输出

- `canonical_name`：标准中文牌名。
- `card_code`：机器可用的牌代码。
- `card_set`：`lenormand_36`。
- `keywords`：基础关键词。
- `interpretation_prompt`：面向回答规划的提示。
- `prohibited_uses`：不得用于事实证明、诊断、预测、诅咒确认或最终决定。

## 边界

牌义速查只提供象征材料，不替代雷诺曼组合分析、现实证据核查或专业建议。
