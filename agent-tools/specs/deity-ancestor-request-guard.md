# Tool Spec：deity_ancestor_request_guard

## 作用

在神明、祖先、供奉、祭拜、祭祖、供桌、许愿和还愿请求进入咨询前，识别神明/祖先命令、灾祸恐吓、危险仪式、专业替代、第三方指认、操控报复、强迫家人、高价法事和反复依赖风险。

## 输出

- `can_continue_deity_ancestor`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 神明/祖先/供奉/还愿只作为文化学习、纪念整理、感恩表达和低风险生活提醒。
- 不确认神明命令、祖先命令、托梦事实、灾祸惩罚、灵体事实或第三方隐私。
- 不提供危险仪式、摄入香灰符水、专业替代、操控报复、强迫他人供奉或高价法事。
