# Tool Spec：aura_chakra_reflection_planner

## 作用

组合气场/脉轮感受记录和符号查询，生成身体感受优先、非诊断、非灵异证明的象征反思计划。

## 输出

- `can_continue_aura_chakra`
- `centers`
- `colors`
- `sensations`
- `symbol_plans`
- `reflection_plan`
- `limits`
- `next_steps`

## 边界

- 先处理现实身体、心理健康和安全支持，再谈象征。
- 不鼓励付费疗愈依赖、反复检测、第三方读心、操控、身份标签或确定疗愈结果。
