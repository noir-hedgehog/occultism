# Tool Spec：color_request_guard

## 作用

在五行颜色、开运色、幸运色、穿搭配色或空间配色请求进入咨询前，识别专业替代、财富保证、外貌标签、高价购买和反复依赖风险。

## 输出

- `can_continue_color`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 颜色只作为文化象征、情绪锚点、空间秩序或低风险行动提醒。
- 不替代医疗、法律、财务、安全、心理健康或形象咨询。
- 不输出招财保证、灾祸恐吓、外貌贬低、高价购买压力或反复依赖流程。
