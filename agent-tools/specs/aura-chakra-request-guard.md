# Tool Spec：aura_chakra_request_guard

## 作用

在气场、脉轮、七轮、灵气、能量场和能量感受请求进入咨询前，识别专业替代、医疗/心理健康、灵异攻击、身份标签、财务赌博、第三方隐私、操控、付费疗愈压力和反复依赖风险。

## 输出

- `can_continue_aura_chakra`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 气场/脉轮只作为象征语言、文化学习、身体感受记录和低风险反思。
- 不用于诊断、治疗、药物替代、精神健康替代、灵异事实确认、第三方读心、投资赌博或付费疗愈诱导。
