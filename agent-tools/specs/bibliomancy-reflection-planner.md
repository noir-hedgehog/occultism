# Tool Spec：bibliomancy_reflection_planner

## 作用

组合书占来源记录和象征查询，生成非决定论、非权威命令、非版权文本获取的书占反思计划。

## 输出

- `can_continue_bibliomancy`
- `source_title`
- `selection_method`
- `symbol_plans`
- `reflection_plan`
- `limits`
- `next_steps`

## 边界

- 医疗心理健康、法律财务、第三方隐私、经典权威命令、长段版权文本或反复依赖请求直接暂停。
- 输出必须把短句/关键词、用户联想、象征解释和现实行动分开。
