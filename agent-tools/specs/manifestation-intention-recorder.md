# Tool Spec：manifestation_intention_recorder

## 作用

记录低风险祈愿/显化咨询中的愿望主题、意图句、象征物、情绪、现实锚点、可控行动、复盘时间和停止条件。

## 输出

- `wish_theme`
- `intention_statement`
- `symbols`
- `emotions`
- `reality_anchor`
- `controllable_actions`
- `review_time`
- `stop_condition`
- `missing_fields`
- `risk_flags`

## 边界

- 记录愿望不等于证明愿望会实现。
- 缺少可控行动、复盘时间或停止条件时必须标记缺失。
