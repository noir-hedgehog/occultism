# Tool Spec：pet_communication_symbol_lookup

## 作用

查询宠物沟通中常见观察和怀念符号的安全解释提示，例如猫、狗、躲起来、呼噜、叫声、尾巴、食欲、门口、亡宠怀念和照片。

## 输出

- `symbol_code`
- `canonical_name`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 不翻译成确定宠物语言，不输出疾病诊断、亡宠灵魂证明、走失位置或第三方责任。
