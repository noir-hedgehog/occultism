# oracle_card_request_guard

守门神谕卡请求中的专业替代、命运断言、财务投机、第三方隐私/操控、超自然恐惧和反复依赖风险。

## 输入

- `request_text` 或 `text`：用户请求。

## 输出

- `can_continue_oracle_card`：是否可继续神谕卡象征咨询。
- `risk_flags`：命中的风险标签。
- `reframed_question`：低风险改写建议。
- `required_boundaries`：必须保留的安全边界。

## 边界

神谕卡只能作为图像、关键词和个人联想的象征反思。不同牌组来源和牌义不同；缺少牌组说明时，不编造固定权威解释。
