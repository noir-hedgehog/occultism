# Tool Spec：sky_omen_symbol_lookup

## 作用

查询天空观察中常见现象和意象的安全象征提示，例如云、龙形云、鸟形云、彩虹、日晕、月晕、闪电、雷声、霞光和雾。

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 输出只用于文化象征和低风险反思。
- 不输出灾祸、死亡、天罚、灵体事实、天气预报、安全预警或专业建议。
