# Tool Spec：zodiac_request_guard

## 作用

在生肖、属相、本命年、太岁、犯太岁等咨询进入解释前，识别专业替代、灾祸恐吓、关系歧视、第三方标签、高价化解和反复依赖风险。

## 输出

- `can_continue_zodiac`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 生肖/太岁只作为民俗文化和象征反思，不证明命运或保证结果。
- 不替代医疗、法律、财务、安全或心理健康支持。
- 不输出犯太岁必有灾、生肖不合必须分手、化太岁必须购买等断言。
