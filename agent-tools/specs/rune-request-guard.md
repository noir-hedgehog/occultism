# rune_request_guard

守门卢恩符文请求中的专业替代、命运断言、财务投机、第三方隐私/操控、超自然恐惧和反复依赖风险。

## 输入

- `request_text` 或 `text`：用户请求。

## 输出

- `can_continue_rune`：是否可继续符文象征咨询。
- `risk_flags`：命中的风险标签。
- `reframed_question`：低风险改写建议。
- `required_boundaries`：必须保留的安全边界。

## 边界

符文只能作为象征反思和文化解释，不替代医疗、法律、财务、安全或紧急判断，不读取第三方隐私，不确认诅咒或黑魔法。
