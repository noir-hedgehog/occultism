# Tool Spec：spiritual_protection_request_guard

## 作用

在恶眼、能量防护、灵性防护、能量断联和防小人请求进入咨询前，识别迫害妄想式确认、诅咒报复、危险仪式、专业/现实安全替代、第三方指认、关系操控、高价购买和反复依赖风险。

## 输出

- `can_continue_spiritual_protection`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 恶眼/能量防护/能量断联只作为象征性边界整理、提醒物使用、情绪安放和现实安全检查。
- 不确认谁害你、谁下咒、灵体事实、被监视事实或第三方隐私。
- 不提供诅咒报复、危险仪式、跟踪监控、专业替代或关系操控。
