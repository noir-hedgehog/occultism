# Tool Spec：moon_phase_request_guard

## 作用

在月相、月亮周期、新月许愿、满月释放、月亮仪式和 lunar-cycle 请求进入咨询前，识别专业替代、医疗/生育/心理健康、危险仪式、显化保证、财务赌博、第三方操控、付费课程压力和反复依赖风险。

## 输出

- `can_continue_moon_phase`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 月相只作为周期隐喻、文化学习、意图整理和低风险复盘。
- 不用于显化保证、天文权威断言、医疗/生育/财务/法律建议、危险仪式、第三方操控或付费诱导。
