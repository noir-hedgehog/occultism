# Tool Spec：aura_chakra_sensation_recorder

## 作用

记录气场/脉轮咨询中的感受事实：中心/脉轮、颜色、身体感受、场景、持续时间、强度、grounding 备注和反思焦点。

## 输出

- `centers`
- `colors`
- `sensations`
- `context`
- `duration`
- `intensity`
- `grounding_notes`
- `missing_fields`
- `risk_flags`

## 边界

- 记录不等于诊断或证明能量状态。
- 胸痛、呼吸困难、持续失眠、惊恐、幻听幻视、强烈痛感或影响功能时暂停象征流程。
