# Tool Spec：planetary_retrograde_request_guard

## 作用

在水逆、行星逆行、星象天气和逆行周期请求进入咨询前，识别专业替代、宿命归因、第三方读心/操控、危险仪式、高价转运、恐慌依赖和灵体事实风险。

## 输出

- `can_continue_planetary_retrograde`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 水逆/行星逆行只作为象征性的复盘、沟通检查、备份和节奏调整提醒。
- 不写成必然灾祸、命中注定、外部惩罚、关系读心或专业决策依据。
