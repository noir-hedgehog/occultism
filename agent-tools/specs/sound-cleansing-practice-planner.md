# Tool Spec：sound_cleansing_practice_planner

## 作用

把声响净化、铃钵、铃铛、音叉、拍手或诵念请求转成短时、低音量、尊重身体和邻里边界的空间复位计划。

## 输出

- `can_continue_sound_cleansing`
- `symbol_plans`
- `practice_plan`
- `limits`
- `next_steps`

## 边界

- 不承诺驱邪、净化确定性、治疗、入睡、转运或灵验结果。
- 不给出贴耳、超大音量、通宵、忍痛继续、靠近婴儿/宠物或扰民步骤。
- 不替代医疗、心理、睡眠、紧急、法律或其他专业支持。
- 不鼓励高价器具、课程套餐、操控销售或反复依赖。
