# Tool Spec：sleep_paralysis_request_guard

## 作用

在鬼压床、压床、睡眠瘫痪、梦魇、梦魔、夜惊和睡前灵异恐惧请求进入咨询前，识别呼吸/胸痛/抽搐、严重睡眠受损、幻听幻视、自伤伤人、危险仪式、专业替代、灵体事实确认、高价法事和反复依赖风险。

## 输出

- `can_continue_sleep_paralysis`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 鬼压床/梦魇只作为睡眠体验记录、身体安定、现实安全检查和象征反思。
- 不确认鬼、邪灵、附身、下咒、灵体压迫、灾祸预告或第三方影响。
- 不提供危险仪式、睡眠剥夺、摄入符水香灰、专业替代或高价法事。
