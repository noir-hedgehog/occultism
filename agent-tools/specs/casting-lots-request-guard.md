# Tool Spec：casting_lots_request_guard

## 作用

在骨、贝壳、石子、符物/小物抛掷占卜请求进入咨询前，识别专业替代、财务赌博、确定预言、灵异恐惧、遗骸/动物伤害、第三方隐私、操控和反复依赖风险。

## 输出

- `can_continue_casting_lots`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 符物抛掷只作为象征性反思、问题整理和低风险行动提醒。
- 不用于遗骸、动物伤害、血祭、赌博、投资、医疗、法律、安全、驱邪证明、第三方窥探、操控或确定预言。
