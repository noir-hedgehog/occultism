# Tool Spec：bibliomancy_symbol_lookup

## 作用

查询书占中常见抽取元素、文本单元、来源类型和意象的安全象征提示，例如页码、随机翻开、句子、关键词、诗、经典/经文、小说、笔记、门和道路。

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 输出只用于阅读触发的象征反思。
- 不确认天意、作者意图、事实证明、诊断、关系结果、法律财务结论或长段版权文本。
