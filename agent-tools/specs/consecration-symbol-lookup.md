# Tool Spec：consecration_symbol_lookup

## 作用

查询开光/加持、净物、干净布、清水擦拭、日光通风、香气边界、意图卡和固定收纳位置等低风险象征提示。

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 象征解释只能服务来源记录、清洁整理、用途确认、无火安全、复盘和停止条件。
- 不承诺灵验，不确认物件招邪，不提供危险仪式或摄入伤身步骤。
- 不诱导高价法事、开光套餐、购买依赖或反复净化。
