# Tool Spec：candle_request_guard

## 作用

守门蜡烛火焰、蜡泪、烛火和 ceromancy 请求，识别明火操作、危险仪式、专业替代、财务赌博、鬼神恐惧、第三方隐私、操控和反复依赖风险。

## 输出

- `can_continue_candle`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 只处理已经安全结束、照片记录或 LED 蜡烛观察。
- 不提供点火、燃烧、烧纸、烧符、放血、密闭燃烧或无人看管火源步骤。
- 不确认鬼神、诅咒或驱邪效果。
