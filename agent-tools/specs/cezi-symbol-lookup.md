# Tool Spec：cezi_symbol_lookup

## 作用

查询测字/拆字中的常见部件、偏旁、结构和形态象征，输出安全解释提示。

## 输入

- `query` / `symbol` / `component`
- `focus`

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 未收录字形线索必须回到用户第一联想和现实问题，不编造固定权威含义。
- 不确认诅咒、附身、驱邪效果、寿命、人格优劣、第三方真实想法或命运结果。
