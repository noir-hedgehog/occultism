# oracle_card_symbol_lookup

查询神谕卡常见图像母题的基础象征、关键词、解释提示和禁止用途。

## 输入

- `query`：母题、牌名关键词或常见中文别名。
- `focus`：咨询焦点，例如 `project_reflection`、`self_boundary`。

## 输出

- `canonical_name`：标准母题名。
- `symbol_code`：机器可用的母题代码。
- `symbol_set`：`common_oracle_card_motifs`。
- `keywords`：基础关键词。
- `interpretation_prompt`：面向回答规划的提示。
- `prohibited_uses`：不得用于事实证明、诊断、预测、灵体命令、诅咒确认或最终决定。

## 边界

母题速查只提供通用象征材料，不替代特定牌组原文、现实证据核查或专业建议。
