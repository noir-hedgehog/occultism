# Tool Spec：aura_chakra_symbol_lookup

## 作用

查询常见脉轮、气场颜色和能量感受的安全象征解释骨架，例如海底轮、脐轮、太阳神经丛、心轮、喉轮、眉心轮、顶轮、白色、蓝色、绿色、发热、沉重和麻感。

## 输出

- `symbol_code`
- `canonical_name`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 不输出诊断、疗愈承诺、灵体证明、身份等级、命运标签或第三方真实想法。
- 不替代医疗、心理健康、药物、紧急安全、法律或财务建议。
