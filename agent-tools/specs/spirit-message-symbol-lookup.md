# Tool Spec：spirit_message_symbol_lookup

## 作用

为通灵/高我讯息中的常见来源隐喻、过程和符号提供安全象征提示，例如高我、守护灵、天使讯息、祖先意象、内在声音、自动书写、羽毛、光、门和名字。

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 不把符号解释成事实证明、灵体命令、医疗建议、关系保证、财务法律判断或第三方真实想法。
- 未知符号由 planner 作为个人意象处理，不编造实体身份。
