# Tool Spec：planetary_retrograde_symbol_lookup

## 作用

查询水星逆行/水逆、金星逆行、火星逆行、木星逆行、土星逆行、逆行阴影期、顺行转向和星象天气等低风险象征提示。

## 输出

- `symbol_code`
- `canonical_name`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 象征提示必须落回复盘、沟通检查、备份、边界和停止查询条件。
- 不确认必然灾祸、行星惩罚、灵体事实、关系读心或专业决策。
