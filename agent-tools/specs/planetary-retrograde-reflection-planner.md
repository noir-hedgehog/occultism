# Tool Spec：planetary_retrograde_reflection_planner

## 作用

组合水逆/行星逆行语境记录和符号查询，生成非宿命化、非专业替代、非读心、非恐慌依赖的复盘与行动检查计划。

## 输出

- `is_valid`
- `can_continue_planetary_retrograde`
- `symbol_plans`
- `reflection_plan`
- `limits`
- `next_steps`

## 边界

- 未知符号只作为私人联想或现实事项，不编造行星惩罚、灾祸或未来保证。
- 计划必须包含现实事项、可控行动、复盘时间和停止查询条件。
