# Tool Spec：tasseography_request_guard

## 作用

守门茶叶占卜、茶渣占卜、咖啡渣占卜和杯底图案解读请求，识别专业替代、财务赌博、第三方隐私、操控、反复依赖和不安全摄入风险。

## 输出

- `can_continue_tasseography`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 茶叶/咖啡渣图案只作为象征反思，不证明事实或预测结果。
- 医疗、法律、财务、安全、心理健康、赌博、第三方窥探、操控和不安全摄入请求必须暂停。
