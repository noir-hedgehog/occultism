# Tool Spec：pet_communication_request_guard

## 作用

在宠物沟通、动物沟通、宠物灵性讯息、亡宠怀念请求进入咨询前，识别兽医替代/急症、走失定位承诺、真实讯息保证、亡宠灵体事实、第三方指认、高价付费和反复依赖风险。

## 输出

- `can_continue_pet_communication`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 宠物沟通只作为象征写作、观察记录、照护计划和哀伤安放。
- 不替代兽医，不定位走失宠物，不确认宠物真实想法或亡宠灵体事实。
