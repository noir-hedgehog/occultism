# Tool Spec：scrying_request_guard

## 作用

守门水晶球、镜面、黑镜、水面凝视和 scrying 请求，识别长时间凝视、追求幻觉、专业替代、财务赌博、鬼神恐惧、第三方隐私、操控、身份标签和反复依赖风险。

## 输出

- `can_continue_scrying`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 只处理短时、已结束的观察或文化学习。
- 不引导长时间凝视、强行入神、睡眠剥夺或追求幻觉。
- 不确认鬼神、灵体、通灵、诅咒或驱邪效果。
