# Tool Spec：synchronicity_request_guard

## 作用

在同步性、天使数字、重复数字、重复征兆和宇宙讯号请求进入咨询前，识别危险寻找、财务/职业/医疗/法律替代、宇宙命令、第三方读心、焦虑反复确认、灵体事实和高价付费风险。

## 输出

- `can_continue_synchronicity`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 同步性只作为个人象征记录、情绪整理和低风险行动反思。
- 不把重复数字或征兆写成宇宙命令、未来保证、天使/灵体事实、专业决策依据或第三方读心。
- 不鼓励开车、过马路或危险环境中寻找征兆。
