# Tool Spec：psychometry_request_guard

## 作用

在物品感应、触物占卜、object reading 和旧物/首饰/遗物能量请求进入咨询前，识别失踪犯罪、第三方隐私、未经同意物件、灵体事实、专业替代、医疗安全、财务法律、真伪归属、付费净化压力和反复依赖风险。

## 输出

- `can_continue_psychometry`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 物品感应只作为象征联想、记忆整理和低风险反思。
- 不确认物品历史、身份、归属、真伪、灵体、诅咒、犯罪线索或第三方事实。
- 不替代医疗、安全检测、报警、法律、鉴定、财务或紧急支持。
