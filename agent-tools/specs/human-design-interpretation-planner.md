# Tool Spec：human_design_interpretation_planner

## 目的

把人类图 chart record、类型、权威、人生角色、中心、通道和闸门组合成低风险象征解释计划。

## 输入

- 与 `human_design_chart_recorder` 相同。

## 输出

- `can_continue_human_design`
- `symbol_plans`
- `interpretation_plan`
- `limits`
- `next_steps`

## 安全边界

- 先声明人类图只作象征反思，不作人格定论、诊断、关系筛选、职业保证或专业建议。
- 每个符号都要回到现实证据、沟通边界、预算/时间限制和可撤回小动作。
- 遇到专业替代、第三方隐私、关系筛选、职业/财务保证、操控、付费压力或反复依赖时暂停。
