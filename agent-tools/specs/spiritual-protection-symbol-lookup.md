# Tool Spec：spiritual_protection_symbol_lookup

## 作用

查询恶眼、蓝眼护符、保护罩/防护罩、能量断联、盐、黑色石、镜子和 grounding 等低风险防护象征提示。

## 输出

- `symbol_code`
- `canonical_name`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 象征提示必须落回情绪、边界、现实安全、提醒物和停止条件。
- 不确认加害者、小人、恶眼来源、下咒事实、灵体事实或第三方隐私。
- 不提供诅咒报复、反噬、危险仪式、跟踪监控、专业替代或关系操控。
