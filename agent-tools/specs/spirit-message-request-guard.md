# Tool Spec：spirit_message_request_guard

## 作用

在通灵、灵媒、高我、守护灵、天使讯息、自动书写和 channeling 请求进入咨询前，识别危机/命令式声音、幻听幻视、专业替代、医疗心理健康、灵体事实确认、第三方隐私/操控、财务法律、付费通灵压力和反复依赖风险。

## 输出

- `can_continue_spirit_message`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 通灵/高我讯息只作为象征写作、文化学习和低风险内在反思。
- 不确认灵体事实、不输出命令、不替代专业支持、不读取第三方、不制造付费通灵或依赖。
