# Tool Spec：psychometry_reflection_planner

## 作用

组合物件记录和物件象征查询，生成非事实确认、非鉴定、非隐私读取的物品感应象征反思计划。

## 输出

- `can_continue_psychometry`
- `object_types`
- `ownership_status`
- `symbol_plans`
- `reflection_plan`
- `limits`
- `next_steps`

## 边界

- 失踪犯罪、第三方隐私、未经同意、灵体事实、专业替代、真伪归属、付费净化或反复依赖请求直接暂停。
- 输出必须把事实、可见特征、用户联想和行动建议分开。
