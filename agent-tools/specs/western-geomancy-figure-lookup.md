# Tool Spec：western_geomancy_figure_lookup

## 目的

查询西洋土占常见 16 个 geomantic figures 和盾形盘位置的低风险象征提示。

## 输入

- `query` / `figure` / `symbol`
- `focus`

## 输出

- `canonical_name`
- `figure_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`
- `next_steps`

## 边界

- 不把 figure 写成确定预言、诊断、财富结果、第三方真实想法或专业意见。
- 对拼写不明、外部应用或私人体系，要求用户说明，不编造权威含义。
