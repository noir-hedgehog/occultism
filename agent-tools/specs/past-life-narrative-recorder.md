# Tool Spec：past_life_narrative_recorder

## 作用

记录前世/阿卡西类请求中的低风险叙事材料，包括梦境或冥想画面、场景、角色、符号、情绪、来源语境、当下现实锚点和同意/隐私备注。

## 输出

- `can_continue_past_life`
- `scenes`
- `roles`
- `symbols`
- `emotions`
- `source_context`
- `reality_anchor`
- `risk_flags`
- `missing_fields`

## 边界

- 记录只证明用户提供了某个叙事画面，不证明前世事实或外部事件。
- 涉及创伤、精神健康、第三方隐私、操控或付费压力时标记为不可继续。
