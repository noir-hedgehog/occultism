# Tool Spec：wealth_luck_request_guard

## 作用

在招财、财运、求财、开财库、补财库、财神、貔貅、金蟾、聚宝盆和 prosperity 请求进入咨询前，识别投资/赌博/借贷、收益保证、债务危机、高价法事、诈骗违法、神明命令、操控他人和反复依赖风险。

## 输出

- `can_continue_wealth_luck`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 招财/财运只作为预算、收入渠道、职业行动、消费边界和复盘提醒。
- 不承诺发财、暴富、稳赚、回本、财运改变或财神/神明保证。
- 不提供投资、借贷、彩票、赌博、违法获利、诈骗、逃税、专业财务替代或高价法事。
