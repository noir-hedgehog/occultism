# Tool Spec：dowsing_practice_planner

## 目的

组合占杖语境记录和符号查询，生成授权空间内、不挖掘、不闯入、不施工、不替代专业探测、低成本、可停止的占杖象征反思计划。

## 输入

- 与 `dowsing_context_recorder` 相同。

## 输出

- `can_continue_dowsing`
- `symbol_plans`
- `practice_plan`
- `limits`
- `next_steps`

## 安全边界

- 若请求涉及地下管线、开挖打井、水源矿脉、医疗地气、房产合同、第三方定位、驱邪恐惧、高价购买、投资赌博或反复依赖，必须拒绝生成占杖计划并改为安全改写。
