# Tool Spec：cezi_request_guard

## 作用

在测字、拆字、字占、字测请求进入咨询前，识别专业替代、财务赌博、确定预言、第三方隐私、操控、灵异恐惧、寿命/人格标签、儿童标签和反复依赖风险。

## 输出

- `can_continue_cezi`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 测字/拆字只作为汉字象征、问题整理和低风险行动提醒。
- 不用于寿命判断、人格优劣、儿童标签、医疗、法律、财务、安全、驱邪证明、第三方窥探、操控或确定预言。
