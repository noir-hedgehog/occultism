# Tool Spec：crystal_symbol_lookup

## 作用

查询常见水晶/能量石的象征关键词、反思问题、行动边界和禁止用途。

## 当前覆盖

- 白水晶
- 紫水晶
- 粉晶/玫瑰石英
- 黄水晶
- 黑碧玺
- 黑曜石
- 萤石
- 拉长石
- 虎眼石
- 绿东陵/绿色砂金石
- 月光石
- 透石膏/selenite

## 输出

- `canonical_name`
- `symbol_code`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

不输出疗愈功效、驱邪证明、招财保证、复合保证或高价购买诱导。
