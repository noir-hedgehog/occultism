# Tool Spec：sleep_paralysis_context_recorder

## 作用

记录低风险鬼压床/梦魇/睡前灵异恐惧请求中的发生模式、醒来状态、身体感、视觉/听觉印象、房间环境、近期压力、睡眠背景、安定动作、白天影响、复盘时间和停止条件。

## 输出

- `episode_pattern`
- `wake_state`
- `body_sensations`
- `perceived_images`
- `room_context`
- `recent_stressors`
- `sleep_context`
- `grounding_actions`
- `daytime_impact`
- `review_time`
- `stop_condition`
- `missing_fields`

## 边界

- 记录体验，不把醒后印象写成灵体事实。
- 严重睡眠受损、呼吸/胸痛/抽搐、幻听幻视、自伤伤人或功能受损时暂停玄学解释。
- 安定动作必须低风险、可撤回、不依赖高价物品或危险仪式。
