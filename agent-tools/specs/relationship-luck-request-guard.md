# Tool Spec：relationship_luck_request_guard

## 作用

识别桃花、姻缘、人缘、月老、红线、粉晶和恋爱运请求，判断是否能继续低风险象征咨询。

## 输出

- `consultation_intent`
- `risk_flags`
- `can_continue_relationship_luck`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 不承诺脱单、复合、结婚、正缘到来或挽回成功。
- 不读取第三方真实想法，不协助跟踪、骚扰、定位、人肉、操控或爱情降头。
- 涉及家暴、威胁、自伤伤人、法律/心理/报警替代或危机支持时暂停玄学流程。
- 不制造和合术、挽回套餐、高价法事或反复依赖。
