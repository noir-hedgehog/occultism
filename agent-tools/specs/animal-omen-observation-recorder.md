# Tool Spec：animal_omen_observation_recorder

## 作用

记录动物征兆咨询中的观察事实：动物、行为、地点、时间、频率、来源、安全背景和反思焦点。先记录现实观察，再进入象征解释。

## 输出

- `animals`
- `behavior`
- `location`
- `timing`
- `frequency`
- `source`
- `safety_context`
- `missing_fields`
- `risk_flags`

## 边界

- 记录不等于确认预兆或灵异事实。
- 涉及咬伤、蜂窝、蛇/蝙蝠、鼠患、虫害、受伤动物或危险接触时暂停象征流程。
