# Tool Spec：spiritual_protection_reflection_planner

## 作用

组合恶眼/能量防护语境记录和符号查询，生成非指认、非报复、非危险仪式、非专业替代、非高价购买的边界整理与现实安全检查计划。

## 输出

- `is_valid`
- `can_continue_spiritual_protection`
- `symbol_plans`
- `reflection_plan`
- `limits`
- `next_steps`

## 边界

- 未知符号只作为私人联想或现实边界提醒，不编造加害者、下咒事实、灵体事实或报复步骤。
- 计划必须包含现实安全背景、可控边界动作、复盘时间和停止条件。
