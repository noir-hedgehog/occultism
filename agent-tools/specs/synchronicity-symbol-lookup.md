# Tool Spec：synchronicity_symbol_lookup

## 作用

查询 1111、222、333、444、555、镜像时间、反复出现的歌、名字、动物、羽毛等同步性符号的低风险象征提示。

## 输出

- `symbol_code`
- `canonical_name`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 象征提示必须落回情绪、现实锚点、可控行动和停止条件。
- 不确认宇宙、天使、神明、亡灵、灵体或外星讯息事实。
- 不证明第三方真实想法，不替代财务、职业、医疗、法律或心理健康判断。
