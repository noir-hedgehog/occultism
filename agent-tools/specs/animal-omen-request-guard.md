# Tool Spec：animal_omen_request_guard

## 作用

在动物征兆、鸟兽虫鱼预兆、鸟进屋、鸟撞窗、乌鸦/猫头鹰叫、蛇/虫/蝴蝶/飞蛾/蜘蛛出现等请求进入咨询前，识别专业替代、伤害动物、公共卫生/虫害、危险接触、确定灾祸、财务赌博、第三方隐私、操控、灵异恐惧和反复依赖风险。

## 输出

- `can_continue_animal_omen`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 动物征兆只作为民俗文化、观察整理和低风险象征反思。
- 不用于灾祸/死亡预言、驱邪证明、伤害动物、危险接触、虫害/公共卫生替代、投资赌博、第三方读心或操控。
