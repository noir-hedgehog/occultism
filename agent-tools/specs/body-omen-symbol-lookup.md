# Tool Spec：body_omen_symbol_lookup

## 目的

查询眼跳、耳鸣、喷嚏、耳热、脸热、手心痒、肉跳、时辰和身体照料备注的安全象征提示。

## 输入

- `query`、`symbol` 或 `omen`
- 可选：`focus`

## 输出

- `canonical_name`
- `symbol_code`
- `symbol_layer`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 安全边界

- 象征提示只用于民俗文化、身体照料和现实复盘，不用于疾病、灾祸、财运、灵体或他人想法断言。
