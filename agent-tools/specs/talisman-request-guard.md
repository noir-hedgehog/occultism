# Tool Spec：talisman_request_guard

## 作用

识别护符、符箓、符咒、灵符、平安符等请求，并在危险仪式、专业替代、诅咒操控、超自然恐惧、高价购买或反复依赖时暂停流程。

## 输出

- `can_continue_talisman`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `clarifying_questions`
- `next_steps`

## 边界

- 只做文化学习、来源记录、象征提醒物和低风险保存/摆放建议。
- 不提供烧符、喝符水、吞符、放血、画符作法、诅咒或操控步骤。
