# Tool Spec：sky_omen_request_guard

## 作用

在天象征兆、云占、看云、彩虹、日晕月晕、雷电和风雨预兆请求进入咨询前，识别灾祸恐吓、天气安全替代、危险天气暴露、专业替代、财务法律、第三方隐私、灵体事实和反复依赖风险。

## 输出

- `can_continue_sky_omen`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 天象/云形征兆只作为文化学习、观察记录和低风险象征反思。
- 不预测灾祸，不替代天气预报、预警、撤离、避雷或现实安全措施。
