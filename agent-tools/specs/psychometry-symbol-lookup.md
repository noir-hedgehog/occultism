# Tool Spec：psychometry_symbol_lookup

## 作用

查询物品感应中常见物件和来源意象的安全象征提示，例如戒指、项链/吊坠、手表、钥匙、照片、旧书、衣物、石头、遗物和二手物。

## 输出

- `canonical_name`
- `symbol_code`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 输出只用于象征联想和现实反思。
- 不确认物品历史、身份、归属、真伪、灵体、诅咒、犯罪线索或第三方隐私。
