# Tool Spec：past_life_request_guard

## 作用

在前世、阿卡西记录、灵魂契约、业力关系和灵魂课题请求进入咨询前，识别记忆恢复/催眠、创伤事实确认、医疗/心理健康替代、宿命论身份标签、关系操控、第三方隐私、财务法律、付费疗愈压力和反复依赖风险。

## 输出

- `can_continue_past_life`
- `consultation_intent`
- `risk_flags`
- `reframed_question`
- `required_boundaries`
- `next_steps`

## 边界

- 前世/阿卡西只作为象征叙事、文化学习和低风险反思。
- 不用于事实证明、记忆恢复、创伤确认、医疗心理健康替代、第三方读心、关系操控、投资法律判断或付费疗愈诱导。
