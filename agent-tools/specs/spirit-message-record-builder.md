# Tool Spec：spirit_message_record_builder

## 作用

记录低风险灵性讯息材料，包括来源、原句、符号、情绪、当下现实锚点、同意/隐私备注和反思焦点。

## 输出

- `can_continue_spirit_message`
- `sources`
- `phrases`
- `symbols`
- `emotions`
- `reality_anchor`
- `risk_flags`
- `missing_fields`

## 边界

- 记录只证明用户提供了某句内在/梦境/写作材料，不证明灵体、亡灵、天使或高我事实。
- 涉及命令式声音、幻听幻视、危机、第三方隐私、付费压力或反复依赖时标记为不可继续。
