# Tool Spec：animal_omen_symbol_lookup

## 作用

查询常见动物、鸟类和昆虫征兆的安全象征解释骨架，例如鸟、乌鸦、猫头鹰、燕子、蝴蝶、飞蛾、蜘蛛、蜜蜂、蛇、猫、狗、鱼、蝙蝠和老鼠。

## 输出

- `symbol_code`
- `canonical_name`
- `category`
- `keywords`
- `interpretation_prompt`
- `reflection_questions`
- `action_guidance`
- `prohibited_uses`

## 边界

- 不输出灾祸、死亡、诅咒、灵体讯息、财运、关系结果或驱邪证明。
- 不替代公共卫生、动物救助、物业、消防、兽医、医疗或安全建议。
