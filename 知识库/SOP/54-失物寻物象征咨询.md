# 失物/寻物象征咨询 SOP

## 目标

把失物占卜、寻物方位、灵摆/塔罗/卦象找东西等请求，转成最后接触记录、路线复盘、区域分层、现实联系渠道、复盘时间和停止条件。不承诺准确定位，也不处理寻人、犯罪定责或隐私追踪。

## 适用

- 本人有权寻找的普通物品，例如钥匙、耳机、钱包、证件、手串、文件、充电器。
- 用户愿意把占卜语言改写成记忆线索和现实搜索计划。
- 目标是低风险、可执行、可停止的寻物复盘。

## 不适用

- 寻人、儿童/老人走失、失联、跟踪、定位他人。
- 走失宠物急症、疑似盗窃、犯罪证据、嫌疑人指认。
- 替代报警、物业、客服、学校、医院、交通失物招领或家人协助。
- 要求保证找到、准确方位、灵验定位、反复占问。

## 流程

1. 运行 `mystic_intake_triage` 判断领域和风险。
2. 运行 `lost_object_request_guard`。
3. 若 `can_continue_lost_object = false`，停止寻物占卜解释，转向现实安全、专业渠道、隐私边界或一次性搜索建议。
4. 若可继续，运行 `lost_object_context_recorder`，记录物品描述、最后看见、路线、可能区域、已查区域、联系渠道、现实行动、风险备注、复盘时间和停止条件。
5. 用 `lost_object_symbol_lookup` 查询最后看见、路线回溯、门口/玄关、口袋/包、桌面/抽屉、交通/座位、联系渠道和复盘停止等线索。
6. 用 `lost_object_search_planner` 生成有限搜索计划。
7. 输出前运行或模拟 `mystic_output_lint`，删除确定定位、嫌疑指认、恐吓、隐私追踪和专业替代表达。

## 输出模板

```text
边界：我不能保证定位或一定找到，也不会用占卜指认谁拿了它；可以把线索整理成一次现实搜索计划。
记录：物品是……；最后看见……；当天路线……；已查……；可联系……
优先搜索：
1. ...
2. ...
3. ...
联系渠道：...
复盘：在……后复盘；若仍未找到，停止反复占问，转向……现实渠道。
```

## 安全边界

- 不说“它一定在某方向/某人那里/今晚必找到”。
- 不判断谁偷了物品，不替代证据、监控、报警或场所管理流程。
- 不处理寻人、隐私定位、跟踪或监视。
- 证件、银行卡、手机、钥匙等高风险物品要提醒挂失、冻结、改密、联系物业/客服等现实动作。
- 每次计划必须有复盘时间和停止条件，避免焦虑式反复占问。
