# SOP：姓名学命名咨询

## 目标

把姓名学请求转成安全、可解释、可复核的名字偏好和使用场景分析。输出可以包含传统文化象征，但不能把姓名写成命运保证或恐吓结论。

## 触发

- “帮我看看这个名字好不好”
- “这个名字五行补不补”
- “宝宝取名/改名/艺名/笔名/品牌名”
- “这个字适不适合放在名字里”
- “名字有没有谐音、避讳、生肖冲突”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain naming`。
2. 若涉及医疗、法律、财务、精神危机、家庭胁迫或专业注册问题，先暂停姓名学判断。
3. 确认使用场景：大名、小名、艺名、笔名、品牌名或其他。
4. 收集候选名字、姓氏、偏好、忌讳、使用者年龄和是否本人/照护者授权。
5. 用 `naming_symbol_lookup` 查询相关维度：字义、字音、字形、五行意象、生肖避讳、用字避讳、场景匹配。
6. 若用户提供一个或多个候选名，用 `naming_candidate_comparator` 生成候选比较表，分开呈现字义、字音、字形、文化避讳和现实使用成本。
7. 若是品牌名、店名或商号，且已提供品类、受众、语气、渠道和候选名，用 `naming_brand_scenario_scorer` 做品牌场景评分。
8. 按“文化联想”和“现实使用”分层解释，不混成命运判断。
9. 对每个候选给出保留点、谨慎点和可调整方向。
10. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这个名字用于什么场景？
- 你最看重字义、读音、五行民俗、家族传统、辨识度还是现实使用便利？
- 是否涉及未成年人、第三方或品牌注册？
- 有没有必须避开的字、谐音、长辈偏好或地域读音？

## 禁止输出

- “这个名字必定富贵/克父母/招灾/婚姻不顺/影响寿命”
- “必须立刻改名，否则会出事”
- “五格显示不能读书/不能结婚/一定失败”
- 未经现实检索就承诺品牌名可注册、可商用或不会侵权。

## 推荐输出结构

```text
安全分级：
使用场景与目标：
候选名字：
维度检查：
候选比较表：
品牌场景评分：
文化象征层：
现实使用层：
可保留点：
需谨慎点：
调整方向：
限制与提醒：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain naming
python3 agent-tools/scripts/naming_symbol_lookup.py --query 字义 --category dimension --focus baby_name
python3 agent-tools/scripts/naming_symbol_lookup.py --query 谐音 --category cultural_check --focus brand_name
python3 agent-tools/scripts/naming_candidate_comparator.py --json '{"request_text":"想比较沐安、清宁哪个更适合宝宝名","name_type":"formal_name","surname":"林","candidates":["沐安","清宁"],"priorities":["字义","读音"],"desired_elements":["water"],"subject_is_minor":true}'
python3 agent-tools/scripts/naming_brand_scenario_scorer.py --json '{"request_text":"给茶饮品牌比较星禾和清朗","candidates":["星禾","清朗"],"category":"茶饮","audience":"年轻上班族","tone":["清爽","年轻"],"channels":["门头","小红书","搜索","域名"]}'
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
