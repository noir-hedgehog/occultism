# SOP：求签与签文象征咨询

## 目标

把求签、抽签、观音签、月老签、灵签和签文解读请求转成安全的文化象征、情绪整理和低风险决策辅助。不得把签文写成必然应验、灾祸恐吓、专业决策依据或操控他人的工具。

## 触发

- “我抽到第十二签，上签，帮我解签”
- “月老签说云开月明是什么意思”
- “帮我模拟抽一签看看工作”
- “签文是不是说明一定会复合/发财/有灾”
- “求签这套文化怎么理解”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain oracle_lot`。
2. 用 `oracle_lot_request_guard` 检查专业替代、确定性命运、操控、第三方隐私和反复抽签依赖。
3. 若涉及医疗、法律、财务、人身安全、操控或“全听签文”，暂停解签并转向现实支持。
4. 用 `oracle_lot_record_builder` 记录问题、签文、签号、签等、来源和抽签方法。
5. 用 `oracle_lot_symbol_lookup` 查询签等、签文层、来源层和主题层。
6. 用 `oracle_lot_interpretation_planner` 生成分层解读计划。
7. 分层输出：来源与限制、签文关键词、象征提醒、现实锚点、低风险行动。
8. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这支签来自寺庙、书籍、应用、用户已抽，还是希望模拟抽签？
- 有签文全文、签号、签等和来源标签吗？
- 问题能否收束为一事一问？
- 是否涉及医疗、法律、财务、安全、操控、第三方隐私或反复抽签？

## 禁止输出

- “这支签保证你们一定复合”
- “下签说明必有大祸”
- “不用看医生/律师，按签文做就行”
- “继续抽到上上签为止”
- “签文证明对方真实想法是……”

## 推荐输出结构

```text
安全分级：
签文来源：
用户问题：
签文/签号/签等：
关键词：
象征层解读：
现实锚点：
低风险行动：
不建议下的结论：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain oracle_lot
python3 agent-tools/scripts/oracle_lot_request_guard.py --text "<user request>"
python3 agent-tools/scripts/oracle_lot_record_builder.py --question "<question>" --lot-text "<lot text>" --source-type temple
python3 agent-tools/scripts/oracle_lot_symbol_lookup.py --query 上签 --focus relationship_reflection
python3 agent-tools/scripts/oracle_lot_interpretation_planner.py --question "<question>" --lot-text "<lot text>" --source-type temple
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
