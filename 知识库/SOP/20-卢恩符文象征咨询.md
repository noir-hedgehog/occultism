# SOP：卢恩符文象征咨询

## 目标

把卢恩符文、rune、Elder Futhark、单符/三符抽取请求转成安全的文化学习、象征反思和低风险记录流程。不得把符文结果当成事实证明、专业建议、预测、诅咒确认、诊断或最终决定。

## 触发

- “帮我抽三枚卢恩符文看项目推进”
- “Fehu 和 Ansuz 在关系问题里是什么意思”
- “用符文看看我要不要辞职”
- “我一直抽符文，抽到满意为止”
- “符文是不是显示我被诅咒”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain rune`。
2. 用 `rune_request_guard` 检查专业替代、命运断言、财务投机、第三方隐私/操控、超自然恐惧和反复依赖。
3. 若涉及医疗、法律、财务、安全、紧急情况、第三方隐私或操控，暂停符文流程，转向现实支持。
4. 确认本轮是文化学习、用户已有抽取结果，还是低风险象征反思。
5. 用 `rune_cast_recorder` 记录问题、牌阵、符文、位置、来源和缺失字段。
6. 用 `rune_symbol_lookup` 查询每枚符文的安全象征。
7. 用 `rune_interpretation_planner` 生成分层计划。
8. 输出顺序必须是：边界说明、问题改写、抽取记录、逐符象征、现实核查、低风险下一步、停止追问条件。
9. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这是文化学习、符文结果记录，还是一次低风险象征反思？
- 这个问题是否涉及医疗、法律、财务、安全、第三方隐私、操控或超自然恐惧？
- 符文来自用户已有抽取、手动输入，还是只是想学习含义？
- 本轮使用单符、三符、过去/现在/未来，还是其他自定义位置？
- 是否正在反复抽同一问题或因符文结果更焦虑？

## 禁止输出

- “符文证明你被诅咒”
- “符文说可以不用医生/律师”
- “这三枚符文表示他一定会回来”
- “继续抽到你想要的答案”
- “符文替你做最终决定”

## 推荐输出结构

```text
安全分级：
问题改写：
抽取记录：
逐符象征：
现实核查：
低风险下一步：
停止追问条件：
不建议下的结论：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain rune
python3 agent-tools/scripts/rune_request_guard.py --text "<user request>"
python3 agent-tools/scripts/rune_cast_recorder.py --text "<question>" --spread-type three_rune --runes "fehu ansuz raidho"
python3 agent-tools/scripts/rune_symbol_lookup.py --query "fehu" --focus "work_reflection"
python3 agent-tools/scripts/rune_interpretation_planner.py --text "<question>" --spread-type three_rune --runes "fehu ansuz raidho"
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
