# SOP：数字象征与号码咨询

## 目标

把数字能量、生命灵数、手机号尾号、车牌号、门牌号和幸运数字请求转成安全的文化象征、偏好整理和现实条件比较。不得收集敏感标识，不得承诺发财、转运、健康、复合或命运改变。

## 触发

- “比较手机号尾号 168 和 739 哪个更顺”
- “数字 8 是不是一定旺财”
- “车牌号里有 4 会不会不吉利”
- “生命灵数 7 怎么理解”
- “想选一个好记、寓意舒服的号码”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain numerology`。
2. 用 `numerology_request_guard` 检查隐私、财富保证、专业替代、第三方标签和未成年人命运标签。
3. 若用户提供身份证、银行卡、验证码、密码或完整手机号，暂停并要求脱敏。
4. 用 `numerology_profile_recorder` 记录脱敏数字片段、使用场景和现实优先条件。
5. 用 `numerology_symbol_lookup` 查询数字或使用场景的象征层。
6. 用 `numerology_interpretation_planner` 生成分层计划。
7. 输出顺序必须是：隐私检查、现实条件、数字象征、偏好建议、低风险行动。
8. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这是手机号尾号、车牌、门牌、生日灵数，还是普通幸运数字？
- 是否已脱敏，只保留尾号或必要片段？
- 现实优先条件是什么：价格、可用性、记忆度、读音、隐私、业务识别还是个人偏好？
- 是否涉及投资、彩票、医疗、法律、第三方人品判断或未成年人命运标签？

## 禁止输出

- “8 一定发财”
- “4 一定倒霉/出事”
- “这个手机号能改命”
- “把完整手机号/身份证/银行卡发来我看”
- “根据号码判断这个人人品不好”

## 推荐输出结构

```text
安全分级：
脱敏状态：
数字材料：
现实优先条件：
数字象征：
偏好比较：
低风险行动：
不建议下的结论：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain numerology
python3 agent-tools/scripts/numerology_request_guard.py --text "<user request>"
python3 agent-tools/scripts/numerology_profile_recorder.py --text "<number material>"
python3 agent-tools/scripts/numerology_symbol_lookup.py --query 8 --focus phone_suffix
python3 agent-tools/scripts/numerology_interpretation_planner.py --text "<number material>"
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
