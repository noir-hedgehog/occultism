# SOP：解梦与梦境象征咨询

## 目标

把梦境请求转成安全的象征反思、情绪整理、文化学习或创作启发。不得把梦解释成疾病诊断、死亡预告、灾祸预兆、诅咒证据或他人真实想法。

## 触发

- “梦见掉牙/蛇/水/考试/死亡是什么意思”
- “这个梦是不是预兆”
- “连续做噩梦怎么办”
- “帮我解梦，梦里我被追、迷路、坠落”
- “这个梦能不能当成创作灵感”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain dream`。
2. 若涉及严重失眠、反复噩梦、创伤困扰、自伤、幻觉、诊断请求或强烈现实恐惧，暂停解梦并建议现实支持。
3. 用 `dream_record_builder` 记录梦境片段、醒后情绪、现实背景、用户目标、主要符号和风险信号。
4. 对主要符号使用 `dream_symbol_lookup`，优先把解释限定为象征层、个人联想和现实背景。
5. 用 `dream_interpretation_planner` 生成解读计划。
6. 分层输出：梦境素材、醒后感受、符号层、现实关联、低风险行动。
7. 如果用户问“是不是预兆/一定会出事/是不是有人害我”，先降级为担忧、压力、转变或边界主题。
8. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 梦醒后最强烈的感受是什么？
- 最近现实中有没有相似的压力、变化、关系、身体疲劳或睡眠问题？
- 你希望把这个梦用于情绪整理、文化象征、创作素材，还是只是想降低不安？
- 这个梦是否反复出现，是否已经影响睡眠或白天功能？

## 禁止输出

- “梦见死亡/掉牙说明亲人会出事”
- “这是疾病、创伤或精神状态的诊断”
- “梦证明有人诅咒你/有鬼/有人一定背叛你”
- “连续噩梦不用找现实支持，按仪式处理就行”
- “这个梦一定预示未来会发生什么”

## 推荐输出结构

```text
安全分级：
梦境素材：
醒后感受：
现实背景：
主要符号：
象征层解读：
现实锚点：
低风险行动：
不建议下的结论：
何时寻求现实支持：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain dream
python3 agent-tools/scripts/dream_record_builder.py --text "<dream text>" --context "<recent waking context>"
python3 agent-tools/scripts/dream_symbol_lookup.py --query 掉牙 --focus self_reflection
python3 agent-tools/scripts/dream_interpretation_planner.py --text "<dream text>" --context "<recent waking context>"
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
