# SOP：塔罗解读

## 适用场景

- 情绪整理
- 关系与工作反思
- 多方案比较
- 对近期状态做象征性复盘

## 不适用场景

- 医疗、法律、投资判断
- 监控或操纵他人
- 要求确定预测死亡、灾难、怀孕、疾病

## 流程

1. 确认问题类型：关系、事业、自我、选择、阶段复盘。
2. 使用 `tarot_spread_selector` 或人工等价规则选择牌阵：单张、三张、二选一、关系镜像。
3. 若用户没有提供实体牌，先确认是否接受模拟抽牌；接受后使用 `tarot_draw_simulator`，并保留 seed。
4. 使用 `tarot_draw_recorder` 或模拟器返回的 `recorded_draw` 记录抽牌：牌名、正逆位、牌位含义。
5. 使用 `tarot_card_lookup` 或 [塔罗牌义速查](../流派/塔罗牌义速查.md) 检索单牌象征。
6. 使用 `tarot_interpretation_planner` 或 [塔罗牌阵案例与逆位策略](../流派/塔罗牌阵案例与逆位策略.md) 生成解读计划。
7. 多牌牌阵使用 `tarot_combination_planner` 生成逆位聚集、大牌权重、花色/宫廷牌聚集和牌位链接。
8. 分层解释：牌位含义、单牌象征、正逆位策略、牌间互动、现实行动。
9. 降低确定性：避免把牌义解释成命令或预言。
10. 使用 `mystic_output_lint` 或人工等价规则检查草稿。
11. 输出 1-3 个可执行建议。

## 推荐牌阵

| 牌阵 | 使用场景 | 牌位 |
| --- | --- | --- |
| 单张 | 每日提醒、快速聚焦 | 当前提醒 |
| 三张 | 状态分析 | 过去/现在/趋势 或 现状/阻碍/建议 |
| 二选一 | 方案比较 | A 路径、B 路径、共同建议 |
| 关系镜像 | 关系反思 | 我方状态、对方可能状态、互动模式、边界建议 |

## 工具命令

```bash
python3 agent-tools/scripts/tarot_spread_selector.py --text "<用户塔罗问题>"
python3 agent-tools/scripts/tarot_draw_simulator.py --spread-id three_card_situation --seed "<可选seed>"
python3 agent-tools/scripts/tarot_draw_recorder.py --json '{"spread_id":"single_focus","cards":[{"card":"愚者","orientation":"正位"}]}'
python3 agent-tools/scripts/tarot_card_lookup.py --card "愚者" --orientation 正位
python3 agent-tools/scripts/tarot_interpretation_planner.py --json '{"question_text":"<问题>","spread_id":"three_card_situation","cards":[{"card":"愚者","orientation":"upright"},{"card":"宝剑三","orientation":"reversed"},{"card":"星币国王","orientation":"upright"}]}'
python3 agent-tools/scripts/tarot_combination_planner.py --json '{"question_text":"<问题>","spread_id":"three_card_situation","cards":[{"card":"愚者","orientation":"upright"},{"card":"宝剑三","orientation":"reversed"},{"card":"星币国王","orientation":"reversed"}]}'
```
