# SOP：易经与六爻占问

## 适用场景

- 一事一问的问题澄清
- 阶段变化、阻碍、下一步行动分析
- 关系、事业、选择等低风险反思

## 不适用场景

- 医疗、法律、投资、借贷、彩票、赌博等专业判断
- 自伤、他伤、家暴、跟踪等即时安全风险
- 操控他人、诅咒、强迫复合
- 反复占问同一问题，且没有新增事实或行动选择

## 流程

1. 使用 `mystic_intake_triage` 做通用安全分级。
2. 使用 `yijing_question_guard` 或人工等价规则检查一事一问、重复占问和高风险专业替代。
3. 若 `can_continue_yijing` 为 `false`，先处理安全、专业支持或问题拆分，不进入起卦。
4. 确认改写后的问题。
5. 使用 `yijing_casting_method_advisor` 选择或校验起卦方式，检查重复占问是否有新增事实或行动选择。
6. 若用户没有自行起卦，先确认是否接受模拟起卦；接受后使用 `yijing_casting_simulator` 并保留 seed。
7. 记录起卦方法、时间、地点/时区、提问背景。
8. 使用 `yijing_hexagram_record` 或模拟器返回的 `recorded_cast` 记录本卦、变爻、变卦。
9. 使用 `yijing_hexagram_lookup` 查询本卦和变卦的结构、关键词和反思问题。
10. 对每个动爻使用 `yijing_line_lookup` 或 [易经384爻索引](../流派/易经384爻索引.md) 查询爻位阶段、阴阳关系和变卦骨架。
11. 若引用卦辞、爻辞、十翼、注疏、现代译注、网络说法或师承说法，使用 `yijing_source_reference_guard` 或 [易经原典注疏来源规范](../流派/易经原典注疏来源规范.md) 做来源分层和引用边界检查。
12. 分层解释：卦象结构、爻位变化、原典/注疏/现代解释层、现实处境、行动建议。
13. 使用 `mystic_output_lint` 或人工等价规则检查草稿。

## 输出结构

```text
安全分级：
问题守门：
问题重述：
起卦记录：
卦象结构：
变化重点：
现实映射：
建议行动：
限制与提醒：
输出检查：
```

## 工具命令

```bash
python3 agent-tools/scripts/yijing_question_guard.py --text "<用户易经问题>"
python3 agent-tools/scripts/yijing_casting_method_advisor.py --text "<改写后的问题>" --method three_coins --user-consent-to-simulation
python3 agent-tools/scripts/yijing_casting_simulator.py --method three_coins --seed "<可选seed>" --question "<改写后的问题>"
python3 agent-tools/scripts/yijing_hexagram_record.py --json '{"question_text":"<改写后的问题>","casting_method":"manual","lines":[7,7,7,7,7,7]}'
python3 agent-tools/scripts/yijing_hexagram_lookup.py --query "<卦名或卦号>" --line 3
python3 agent-tools/scripts/yijing_line_lookup.py --query "<卦名或卦号>" --line 3
python3 agent-tools/scripts/yijing_source_reference_guard.py --text "<原文、注疏或网络断语>" --source-type internet_claim
```
