# SOP：灵摆占卜象征咨询

## 目标

把灵摆、摆锤、pendulum、yes/no 摆动和校准请求转成安全的自我反思、偏好澄清和低风险记录流程。不得把灵摆结果当成事实证明、专业建议、预测、诊断或最终决定。

## 触发

- “用灵摆问我要不要先联系对方”
- “灵摆顺时针是不是代表 yes”
- “灵摆左右摆是什么意思”
- “帮我设计一个灵摆校准流程”
- “我一直问灵摆同一个问题，越问越焦虑”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain pendulum`。
2. 用 `pendulum_request_guard` 检查专业替代、决定论、财务投机、第三方操控、超自然恐惧确认和反复依赖。
3. 若涉及医疗、法律、财务、安全、紧急情况、第三方隐私或操控，暂停灵摆流程，转向现实支持。
4. 将 yes/no 问题改写成开放反思问题：证据、偏好、边界、可控下一步。
5. 用 `pendulum_session_recorder` 记录问题、校准说明、摆动结果、同意和缺失字段。
6. 用 `pendulum_symbol_lookup` 查询摆动或答案状态的安全象征。
7. 用 `pendulum_interpretation_planner` 生成分层计划。
8. 输出顺序必须是：边界说明、问题改写、会话记录、象征提示、现实核查、停止追问条件。
9. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这是文化学习、灵摆校准，还是一次低风险自我反思？
- 这个问题是否涉及医疗、法律、财务、安全、第三方隐私或操控？
- 用户是否愿意把 yes/no 改写成“我还需要看哪些证据/偏好/下一步”？
- 本次 yes/no/不确定如何校准？是否有不明确或环境干扰？
- 是否正在反复追问同一个问题或因灵摆结果更焦虑？

## 禁止输出

- “灵摆已经证明他还爱你”
- “灵摆说可以不用看医生/律师”
- “灵摆显示这里有鬼/被诅咒”
- “继续问到它给你想要的答案”
- “灵摆替你做最终决定”

## 推荐输出结构

```text
安全分级：
问题改写：
会话记录：
摆动象征：
现实核查：
低风险下一步：
停止追问条件：
不建议下的结论：
```

## 工具命令

```bash

```
