# SOP：占星/星盘象征咨询

## 目标

把占星请求处理为安全、非决定论、可复盘的象征咨询流程。agent 可以解释星座、行星、宫位、四轴点和相位，但不能生成未经验证的星盘、替代专业建议或宣称命运必然。

## 输入

- 用户原始请求
- 用户目标和问题焦点
- 星盘字段或外部排盘来源
- 本人/第三方/未成年人同意状态
- 风险信号和高风险专业领域

## 流程

1. **通用 intake**
   - 运行 `mystic_intake_triage`。
   - 若风险为 red/orange，先暂停占星解读，转向安全支持、专业支持或低风险 grounding。

2. **资料与同意确认**
   - 若只问星座/术语文化含义，可直接进入符号解释。
   - 若需要星盘，请用户提供外部排盘字段，而不是让 agent 编造或推算。
   - 若涉及第三方或未成年人，确认同意；没有同意时只做匿名文化解释。

3. **问题重述**
   - 把“会不会”“是不是命中注定”“他一定怎样”改写为可观察问题。
   - 示例：把“我们是不是绝配”改为“这些符号能提示哪些互动需求和沟通边界”。

4. **符号查询**
   - 使用 `astrology_symbol_lookup` 查询星座、行星、宫位、四轴点或相位。
   - 单个符号只作为解释入口，不单独下结论。

5. **现实映射**
   - 将象征语言映射到行为、需求、压力、沟通方式、环境和低风险行动。
   - 每个判断都配一个现实证据问题或验证动作。

6. **输出检查**
   - 运行或心智应用 `mystic_output_lint`。
   - 移除确定性恐吓、专业替代、操控他人、隐私越界和绝对化预测。

## 输出结构

```text
安全分级：
资料来源与同意：
问题重述：
符号清单：
象征解释：
现实映射：
可观察信号：
低风险建议：
限制与提醒：
```

## 禁止输出

- “你们一定结婚/必分手/绝配/命中注定。”
- “这个相位说明你一定有病/会出事/会发财。”
- “按星盘你应该停药、贷款、辞职、起诉。”
- “我可以分析你前任的精确出生资料，即使对方不知道。”

## 验收清单

- 已声明占星是象征反思，不是事实预测。
- 已说明星盘字段来源和资料限制。
- 已处理第三方、未成年人和精确出生资料隐私。
- 已把问题转成可观察信号和低风险行动。
- 最终文本没有决定论、恐吓、专业替代或隐私越界。
