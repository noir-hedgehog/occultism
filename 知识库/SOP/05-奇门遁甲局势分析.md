# SOP：奇门遁甲局势分析

## 适用场景

- 局势分析
- 行动方案比较
- 择时/推进节奏的象征性参考
- 用户已提供外部排盘结果，需要结构化记录和解释

## 不适用场景

- 医疗、法律、投资、借贷、彩票、赌博等专业判断
- 自伤、他伤、家暴、跟踪等即时安全风险
- 操控他人、诅咒、报复
- 没有明确起局方法却要求确定结论

## 流程

1. 使用 `mystic_intake_triage` 做通用安全分级。
2. 用户询问置闰/拆补、飞盘/转盘、茅山等派别或盘式差异时，先使用 `qimen_school_reference` 说明会影响的字段、所需前提和混派风险。
3. 使用 `qimen_method_guard` 确认起局时间、地点、时区、派别、真太阳时策略和节气来源。
4. 若 `can_generate_chart=false` 且用户没有外部盘式，不编造排盘；先补齐错误项或改为方法说明。
5. 若用户提供外部盘，标记来源和方法限制，不重新生成宫位。
6. 使用 `qimen_chart_record` 或人工等价规则记录阴阳遁、局数、九宫、门、星、神、干、值符/值使和用神。
7. 若盘式不完整，先说明缺失字段和限制。
8. 使用 `qimen_focus_selector` 或人工等价规则选择候选用神和读盘顺序。
9. 分层解释：用神、相关宫位、门星神干组合、现实行动。
10. 使用 `mystic_output_lint` 或人工等价规则检查草稿。
