# SOP：空间净化与驱邪安全咨询

## 定位

本 SOP 只提供低风险的文化性、心理稳定性和空间整理建议。不得确认“有鬼”“被附身”“被下咒”，不得提供危险仪式或恐吓性解释。

## 流程

1. 先问现实风险：是否有人身危险、精神失控、持续失眠、幻听幻视、燃气/霉菌/电路问题。
2. 使用 `ritual_safety_check` 做危险动作分级。
3. 使用 `ritual_source_example_lookup`、`ritual_source_guard` 或 [民俗仪式资料来源规范](../流派/民俗仪式资料来源规范.md) 标注来源：地域民俗、宗教传统、现代身心实践、商业改编、个人经验或未知来源。
4. 使用 `ritual_low_risk_protocol` 或 [仪式低风险真实案例集](../流派/仪式低风险真实案例集.md) 选择低风险流程。
5. 若 Red/Orange：停止玄学判断，建议现实支持，只给低风险替代。
6. 若 Green/Yellow：把问题重述为空间压力、情绪压力或象征性净化需求。
7. 推荐低风险行动：通风、清洁、断舍离、灯光、香气替代、音乐、写下担忧并收纳。
8. 如用户坚持仪式：只给无火、无药物摄入、无伤害、无封闭燃烧的版本。
9. 收尾：鼓励记录睡眠、情绪和空间变化，而不是反复验证恐惧。

## 禁止内容

- 诅咒、报复、控制他人
- 自残、放血、禁食、极端熬夜
- 密闭空间燃烧、未知草药摄入、酒精助燃
- 要求用户切断医疗/心理支持

## 工具命令

```bash
python3 agent-tools/scripts/ritual_safety_check.py --text "<用户仪式请求>"
python3 agent-tools/scripts/ritual_source_example_lookup.py --text "<用户仪式请求或资料片段>"
python3 agent-tools/scripts/ritual_source_guard.py --text "<用户仪式请求或资料片段>" --source-type unknown
python3 agent-tools/scripts/ritual_low_risk_protocol.py --text "<用户仪式请求>"
```
