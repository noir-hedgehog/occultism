# SOP：手相/面相象征咨询

## 目标

把手相、面相、痣相和相术请求转成安全的文化象征、个人叙事和现实整理。不得从掌纹、五官、痣或外貌判断健康、寿命、人品、贵贱、婚恋结局、财富成败或社会价值。

## 触发

- “帮我看手相，生命线/事业线/感情线代表什么”
- “面相里的鼻相、额头、眉眼怎么理解”
- “痣相在传统文化里有什么说法”
- “只做象征解读，不要说命定”
- “相术能不能作为写作素材或文化设定”

## 步骤

1. 运行 `mystic_intake_triage`，必要时指定 `--domain physiognomy`。
2. 用 `physiognomy_request_guard` 确认本人/同意、咨询目标和风险边界。
3. 若涉及健康诊断、寿命、短命、死亡、旺克、贵贱、颜值歧视、第三方隐私、招聘筛选或确定命运，暂停解读并改写问题。
4. 用 `physiognomy_observation_recorder` 记录用户自述或授权观察，不分析照片，不补写未提供的外貌细节。
5. 对主要特征使用 `physiognomy_symbol_lookup` 查询象征层。
6. 用 `physiognomy_interpretation_planner` 生成分层计划。
7. 分层输出：同意状态、观察素材、符号层、现实锚点、可自查问题、低风险行动。
8. 用 `mystic_output_lint` 检查最终草稿。

## 必问问题

- 这是你本人的手相/面相，还是已获得对方同意？
- 用户提供的是自述观察、授权观察，还是只想做匿名文化学习？
- 想讨论哪些具体特征：生命线、智慧线、感情线、事业线、掌丘、额头、眉、眼、鼻、嘴、下巴或痣？
- 目标是文化学习、自我反思、创作素材，还是现实决策整理？

## 禁止输出

- “生命线短说明短命/有病”
- “鼻相说明一定发财/没财运”
- “眉眼能看出这个人人品不好”
- “她的面相克夫/旺夫”
- “用相术筛掉不适合录用的人”
- “根据照片判断对方性格、健康或隐私”

## 推荐输出结构

```text
安全分级：
同意状态：
用户提供的观察：
主要符号：
象征层解读：
现实锚点：
可自查问题：
低风险行动：
不建议下的结论：
```

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<user request>" --domain physiognomy
python3 agent-tools/scripts/physiognomy_request_guard.py --text "<user request>" --subject-is-self
python3 agent-tools/scripts/physiognomy_observation_recorder.py --text "<observation>" --subject-is-self
python3 agent-tools/scripts/physiognomy_symbol_lookup.py --query 生命线 --focus self_reflection
python3 agent-tools/scripts/physiognomy_interpretation_planner.py --text "<observation>" --subject-is-self
python3 agent-tools/scripts/mystic_output_lint.py --text "<draft answer>"
```
