# 西洋土占盾形盘象征咨询 SOP

## 适用范围

适用于西洋土占、盾形占、盾盘、土占盘、geomancy、Western geomancy、shield chart、geomantic figure、母亲图、见证者和裁判者等请求。目标是把四行点或外部应用给出的盾形盘整理成低风险象征反思，而不是确定预言、专业建议或灵异证明。

## 硬性边界

- 不替代医疗、法律、财务、安全、心理健康、紧急支持或当事人沟通。
- 不用盘面决定投资、贷款、彩票、赌博、治疗、报警、诉讼或高风险现实事项。
- 不窥探第三方真实想法，不做操控、报复、强制复合或关系命令。
- 不确认附身、诅咒、恶灵、驱邪效果或神秘事实。
- 不反复起盘直到满意；必须固定问题、盘面来源和复盘时间。

## 标准流程

1. 运行 `mystic_intake_triage` 判断领域和风险。
2. 运行 `western_geomancy_request_guard`。
3. 若出现专业替代、财务赌博、确定预言、灵异恐惧、第三方窥探、操控或反复依赖，暂停西洋土占流程，改为现实支持、边界整理或低风险复盘。
4. 运行 `western_geomancy_chart_recorder` 记录问题、起盘来源、生成方式、母亲图、女儿图、侄子图、见证者、裁判者和缺失字段。
5. 运行 `western_geomancy_figure_lookup` 查询图形或盘位提示。
6. 运行 `western_geomancy_interpretation_planner` 生成解释顺序。
7. 输出时保留象征性、可能性、现实证据和可撤回行动。
8. 运行 `mystic_output_lint`。

## 信息收集

- 用户问题和现实背景。
- 起盘来源：用户已起盘、同意模拟、外部应用、历史案例或文化学习。
- 生成方式：四行点、应用生成、书本示例或自定义体系。
- 四个母亲图、女儿图、侄子图、两个见证者和裁判者。
- 用户关注焦点、现实约束、可控行动和复盘时间。
- 是否存在专业替代、财务赌博、灵异恐惧、第三方窥探、操控、确定预言或反复依赖。

## 输出格式

1. 边界声明：盘面只作象征反思。
2. 盘面摘要：来源、方法、关键图形、缺失字段。
3. 象征层：母亲图输入、见证者张力、裁判者收束。
4. 现实层：证据、当事人沟通、风险约束和可控行动。
5. 停止条件：焦虑升高、反复起盘、想把盘面当命令或涉及高风险事项。

## 常见误区

- 把裁判者写成命令或最终判决。
- 把大吉、小吉、获得等图形写成收益保证。
- 把失去、忧伤、牢笼写成厄运或诅咒。
- 混淆西洋土占和中文语境中的风水。
- 在盘面不完整时自行补图。
