# SOP：风水图片/文字观察记录

## 定位

本 SOP 用于风水审视前的事实记录。目标是把用户的照片说明、户型描述或口头观察拆成可见事实，避免 agent 直接跳到“破财”“有煞”“必然影响健康”等不可审计判断。

## 适用场景

- 用户上传房间、工位、店铺、玄关、厨房等照片并要求看风水
- 用户提供空间文字描述，希望整理成检查清单
- 需要把传统术语解释建立在可见事实之后

## 不适用场景

- 燃气、电路、霉菌、门锁、人身安全等现实风险尚未处理
- 用户要求从照片判断灾祸、疾病、财富、婚姻、超自然实体
- 图片无法确认具体位置，却要求 agent 直接下结论

## 流程

1. 先运行 `mystic_intake_triage` 做通用安全分级。
2. 使用 `fengshui_observation_recorder` 记录可见事实、区域、对象和现实安全信号。
3. 若 `can_continue_fengshui` 为 `false`，先处理现实安全，不进入传统解释。
4. 对每条观察先写事实，再写可能的传统术语候选。
5. 将观察记录交给 `fengshui_space_checklist` 生成形法检查项。
6. 将候选调整交给 `fengshui_recommendation_ranker` 排序。
7. 最终回答必须区分事实、解释、建议和限制。

## 输出结构

```text
输入来源：
空间类型：
可见事实：
现实安全信号：
缺失信息：
可解释术语候选：
下一步检查：
限制与提醒：
```

## 工具命令

```bash
python3 agent-tools/scripts/fengshui_observation_recorder.py --text "<照片说明或空间描述>"
python3 agent-tools/scripts/fengshui_space_checklist.py --text "<整理后的空间描述>"
python3 agent-tools/scripts/fengshui_recommendation_ranker.py --json '{"recommendations":[{"recommendation":"清理门后杂物"}]}'
```
