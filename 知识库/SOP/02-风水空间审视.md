# SOP：风水空间审视

## 定位

风水类输出优先结合空间体验、动线、采光、通风、收纳、隐私与心理安全，再用传统术语作为解释语言。避免把空间问题说成必然导致灾祸。

## 信息收集

- 房屋类型：卧室、客厅、办公室、店铺
- 主要困扰：睡眠、专注、关系、财务感受、压迫感
- 空间描述：门窗、床/桌/灶位置、光线、噪音、杂物
- 方位信息：若用户知道，可记录；不知道也可做形法审视
- 图片：可选；没有图片时用文字检查表

## 流程

1. 做安全筛查：睡眠严重异常、霉菌、电路、煤气等先提示现实检查。
2. 若用户提供图片说明或空间描述，先使用 `fengshui_observation_recorder` 记录可见事实。
3. 划分区域：入口、休息、工作、烹饪、收纳、过道。
4. 使用 `fengshui_space_checklist` 或人工等价规则检查形法：冲、压、堵、暗、乱、漏、尖角、背后无靠等。
5. 若用户要求玄空飞星、八宅、三合/三元、择日或罗盘坐向判断，先使用 `fengshui_school_guard`；字段不足时不排盘、不混派、不下吉凶结论。
6. 需要参考阳宅案例时，使用 `fengshui_yangzhai_case_library` 或 [风水阳宅案例库](../流派/风水阳宅案例库.md) 检索相似场景。
7. 若用户提供明确方位，使用 `fengshui_bagua_mapper` 或人工等价规则做八卦方位映射；不确定方位时不编造罗盘结果。
8. 映射现实体验：动线、噪音、隐私、注意力、卫生。
9. 使用 `fengshui_recommendation_ranker` 或人工等价规则排序建议：现实安全优先，其次低成本、可逆、非危险调整。
10. 给出调整建议：优先选择低成本、可逆、无危险的动作。
11. 标记传统说法、理气派别和现代解释的边界。

## 工具命令

```bash
python3 agent-tools/scripts/fengshui_school_guard.py --text "<玄空/八宅/罗盘/坐向请求>"
python3 agent-tools/scripts/fengshui_observation_recorder.py --text "<照片说明或空间描述>"
python3 agent-tools/scripts/fengshui_space_checklist.py --text "<用户空间描述>"
python3 agent-tools/scripts/fengshui_yangzhai_case_library.py --query "<阳宅场景描述>"
python3 agent-tools/scripts/fengshui_bagua_mapper.py --text "<带方位的空间描述>"
python3 agent-tools/scripts/fengshui_recommendation_ranker.py --json '{"recommendations":[{"recommendation":"清理门后杂物"}]}'
```
