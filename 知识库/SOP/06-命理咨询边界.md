# SOP：八字与紫微斗数命理咨询

## 适用场景

- 用户希望用八字、四柱或紫微斗数做自我理解
- 事业、关系、阶段变化的低风险复盘
- 命理文化学习、术语解释、命盘资料整理

## 不适用场景

- 寿命、死期、灾祸、疾病、婚育、财富的确定性预测
- 医疗、法律、财务或心理健康问题的专业替代
- 未经同意分析第三方命盘
- 对未成年人做终身定性
- 用命理操控他人或制造恐惧

## 流程

1. 使用 `mystic_intake_triage` 做通用安全分级。
2. 使用 `bazi_ziwei_intake_guard` 检查资料完整度、隐私同意、未成年人和宿命论风险。
3. 若 `can_continue_mingli` 为 `false`，暂停命理解释，转为安全支持、专业支持、匿名文化解释或问题改写。
4. 确认用户要用八字、紫微斗数，还是只做命理文化解释。
5. 用户询问子平、传统八字、现代综合、三合、四化、中州或混派时，先使用 `mingli_school_reference` 说明字段差异和混用风险。
6. 收集或确认出生日期、出生时间、出生地点、历法类型和分析焦点。
7. 使用 `bazi_ziwei_chart_record` 标注排盘方式、时区、真太阳时策略、派别和不确定字段。
8. 若 `bazi_ziwei_chart_record` 返回 `is_valid=false`，先补齐参数，不进入命理解读。
9. 使用 `mingli_symbol_lookup` 或人工等价规则解释干支、十神、宫位和星曜。
10. 输出时按“象征结构 -> 现实映射 -> 可观察信号 -> 低风险建议”分层。
11. 使用 `mystic_output_lint` 或人工等价规则检查最终草稿。

## 工具命令

```bash
python3 agent-tools/scripts/mystic_intake_triage.py --text "<用户命理请求>"
python3 agent-tools/scripts/bazi_ziwei_intake_guard.py --text "<用户命理请求>"
python3 agent-tools/scripts/mingli_school_reference.py --query "子平和紫微三合能混着看事业吗"
python3 agent-tools/scripts/bazi_ziwei_chart_record.py --json '{"system":"bazi","birth_date":"<YYYY-MM-DD>","birth_time":"<HH:MM>","birth_place":"<地点>","calendar_type":"solar","timezone":"Asia/Shanghai","solar_time_strategy":"not_applied","chart_source":"external_calculator"}'
python3 agent-tools/scripts/mingli_symbol_lookup.py --query 七杀 --category ten_god --focus career
python3 agent-tools/scripts/mystic_output_lint.py --text "<草稿输出>"
```
