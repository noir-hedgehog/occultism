# 身体征兆/眼跳/耳鸣/喷嚏象征咨询 SOP

## 适用范围

- 用户询问眼跳、左眼跳、右眼跳、耳鸣、耳热、喷嚏、脸热、手心痒、肉跳等民俗征兆是什么意思。
- 用户想记录一次本人低风险身体征兆，并把它整理成民俗象征、身体照料提醒和现实复盘。
- 用户想学习身体征兆类民俗对照表、时辰说法或文化来源。

## 不适用范围

- 诊断、治疗、用药、停药、检查替代、急症判断或心理健康替代。
- 持续、突发、严重、单侧、疼痛、视力/听力下降、胸痛、呼吸困难、麻木、晕厥、发烧、孕期或影响功能的症状。
- 彩票、赌博、投资、签约、重大决定或灾祸断言。
- 替第三方身体反应贴标签、读心、判断命运或确认灵异原因。
- 按眼球、放血、自伤、危险试验、驱邪恐惧或反复查兆到安心。

## 标准流程

1. 运行 `mystic_intake_triage`，识别医疗、财务、第三方、灵异恐惧和反复依赖风险。
2. 运行 `body_omen_request_guard`。
3. 若 `can_continue_body_omen=false`，暂停民俗解读，转向医疗/安全/现实支持。
4. 运行 `body_omen_context_recorder`，记录：
   - 征兆类型
   - 身体位置
   - 发生时间和时辰语境
   - 持续时间或频率
   - 感受描述
   - 健康背景和医疗边界
   - 睡眠、屏幕、压力、咖啡因、环境刺激等普通背景
   - 现实约束和停止条件
5. 用 `body_omen_symbol_lookup` 查询眼跳、耳鸣、喷嚏、耳热、脸热、手心痒、肉跳、时辰或身体照料备注。
6. 用 `body_omen_reflection_planner` 生成反思计划。
7. 输出前运行 `mystic_output_lint` 或等价检查。

## 输出格式

- 边界声明：身体征兆只作民俗象征和身体照料提醒，不作诊断、灾祸、财运、灵体或他人想法证明。
- 记录摘要：征兆、位置、时间、持续频率、普通背景和缺失字段。
- 象征反思：用“可能提醒”“可以当作”表达休息、节奏、刺激、社交感、预算或身体照料。
- 现实核查：休息、饮水、用眼间隔、降低刺激、观察是否持续、必要时找专业支持。
- 停止条件：一次记录即可，避免反复查兆。

## 禁用表达

- “这是疾病/灾祸/死亡/破财的确定预兆。”
- “不用看医生，按这个时辰解就行。”
- “左眼跳一定发财，右眼跳一定有灾。”
- “他眼跳说明他想你/对不起你。”
- “耳鸣是灵体/中邪/诅咒。”
- “今天可以买彩票/梭哈/投资。”
