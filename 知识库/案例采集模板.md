# 案例采集模板

本页把案例验证 Backlog 转成可填写的采集模板。模板用于收集实用案例、来源审计和边界反例，随后再交给对应工具与人工审校。

## 摘要

| 指标 | 当前值 |
| --- | --- |
| 来源 Backlog | 61 |
| 模板 | 61 |
| 优先级 | `P0` 15、`P1` 34、`P2` 12 |
| 目标产物 | `boundary_counterexample_and_safe_rewrite` 12、`reviewed_practical_case_candidate` 15、`source_audit_or_correction_note` 34 |

## 模板

### template-CV-P0-001-aura_chakra 气场/脉轮/能量感受

- 来源 Backlog：`CV-P0-001-aura_chakra`
- 领域：`aura_chakra`
- 优先级：`P0`
- 目标产物：`reviewed_practical_case_candidate`
- 证据模式：`mixed`

#### 采集字段

| 字段 | 类型 | 提示 | 示例 | 流向 |
| --- | --- | --- | --- | --- |
| `experience_text` | `string` | 用户体验的脱敏描述，避免把感受直接确认为超自然事实。 | 入睡前反复觉得有人在房间里，醒来后仍然紧张。 | `consultation_case_recorder` |
| `duration_or_frequency` | `string` | 持续时长、发生频率或触发周期。 | 近两周每周 3 次，主要发生在熬夜后。 | `consultation_case_recorder` |
| `ordinary_triggers` | `array<string>` | 可先排查的普通诱因。 | 睡眠不足；咖啡因；近期压力；药物变化。 | `consultation_case_recorder` |
| `red_flags_checked` | `array<string>` | 已检查的身体、心理或现实安全红旗。 | 自伤风险为否；持续幻听为否；睡眠严重受损需现实支持。 | `consultation_case_recorder` |
| `care_action` | `string` | 现实照料动作或专业支持边界。 | 先记录睡眠和压力触发；若持续恶化，建议寻求专业支持。 | `consultation_case_recorder` |
| `follow_up_window_days` | `integer` | 回访窗口，单位为天。 | 14 | `consultation_case_recorder` |
| `observed_changes` | `array<string>` | 回访中观察到的变化，必须允许无变化或反向变化。 | 夜间醒来次数减少；仍不能排除工作压力影响。 | `consultation_case_recorder` |
| `validation_result` | `enum` | 验证结果：supports_practical_use、mixed、no_support、safety_only 或 unverified。 | mixed | `consultation_case_recorder` |
| `reviewer` | `string` | 审校人、维护者或角色名。 | internal-reviewer | `consultation_case_recorder` |

#### 推荐工具流

- `consultation_execution_runner`：先执行安全白名单子集，确认哪些步骤可程序化、哪些需要 Agent 或人工补字段。 输入字段：`experience_text`
- `consultation_handoff_builder`：把低风险行动、草稿和复核点整理成 Agent/审校交接包。 输入字段：`care_action`, `experience_text`
- `consultation_case_recorder`：记录回访、验证结果、脱敏摘要和人工审校状态。 输入字段：`experience_text`, `follow_up_window_days`, `observed_changes`, `validation_result`, `reviewer`

#### 复核清单

- baseline 与 follow-up 使用同一观察口径。
- 低风险行动可停止、可撤回、不会替代医疗/法律/财务/现实安全建议。
- 记录无变化、负向变化或普通诱因，不能只保留支持性案例。

#### 验收标准

- 包含 baseline 与 follow-up，不只记录一次性解读。
- 至少一个行动是低成本、可撤回、可现实观察的。
- 用 consultation_case_recorder 生成候选记录，且 validation_result 不再是 unverified。

#### 示例 Payload

```json
{
  "experience_text": "入睡前反复觉得有人在房间里，醒来后仍然紧张。",
  "duration_or_frequency": "近两周每周 3 次，主要发生在熬夜后。",
  "ordinary_triggers": [
    "睡眠不足",
    "咖啡因",
    "近期压力",
    "药物变化。"
  ],
  "red_flags_checked": [
    "自伤风险为否",
    "持续幻听为否",
    "睡眠严重受损需现实支持。"
  ],
  "care_action": "先记录睡眠和压力触发；若持续恶化，建议寻求专业支持。",
  "follow_up_window_days": 14,
  "observed_changes": [
    "夜间醒来次数减少",
    "仍不能排除工作压力影响。"
  ],
  "validation_result": "mixed",
  "reviewer": "internal-reviewer",
  "domain": "aura_chakra"
}
```

- 领域：`sleep_paralysis`
- 优先级：`P0`
- 目标产物：`reviewed_practical_case_candidate`
- 证据模式：`mixed`

#### 采集字段

| 字段 | 类型 | 提示 | 示例 | 流向 |
| --- | --- | --- | --- | --- |
| `experience_text` | `string` | 用户体验的脱敏描述，避免把感受直接确认为超自然事实。 | 入睡前反复觉得有人在房间里，醒来后仍然紧张。 | `consultation_case_recorder` |
| `duration_or_frequency` | `string` | 持续时长、发生频率或触发周期。 | 近两周每周 3 次，主要发生在熬夜后。 | `consultation_case_recorder` |
| `ordinary_triggers` | `array<string>` | 可先排查的普通诱因。 | 睡眠不足；咖啡因；近期压力；药物变化。 | `consultation_case_recorder` |
| `red_flags_checked` | `array<string>` | 已检查的身体、心理或现实安全红旗。 | 自伤风险为否；持续幻听为否；睡眠严重受损需现实支持。 | `consultation_case_recorder` |
| `care_action` | `string` | 现实照料动作或专业支持边界。 | 先记录睡眠和压力触发；若持续恶化，建议寻求专业支持。 | `consultation_case_recorder` |
| `follow_up_window_days` | `integer` | 回访窗口，单位为天。 | 14 | `consultation_case_recorder` |
| `observed_changes` | `array<string>` | 回访中观察到的变化，必须允许无变化或反向变化。 | 夜间醒来次数减少；仍不能排除工作压力影响。 | `consultation_case_recorder` |
| `validation_result` | `enum` | 验证结果：supports_practical_use、mixed、no_support、safety_only 或 unverified。 | mixed | `consultation_case_recorder` |
| `reviewer` | `string` | 审校人、维护者或角色名。 | internal-reviewer | `consultation_case_recorder` |

#### 推荐工具流

- `consultation_execution_runner`：先执行安全白名单子集，确认哪些步骤可程序化、哪些需要 Agent 或人工补字段。 输入字段：`experience_text`
- `consultation_handoff_builder`：把低风险行动、草稿和复核点整理成 Agent/审校交接包。 输入字段：`care_action`, `experience_text`
- `consultation_case_recorder`：记录回访、验证结果、脱敏摘要和人工审校状态。 输入字段：`experience_text`, `follow_up_window_days`, `observed_changes`, `validation_result`, `reviewer`

#### 复核清单

- baseline 与 follow-up 使用同一观察口径。
- 低风险行动可停止、可撤回、不会替代医疗/法律/财务/现实安全建议。
- 记录无变化、负向变化或普通诱因，不能只保留支持性案例。

#### 验收标准

- 包含 baseline 与 follow-up，不只记录一次性解读。
- 至少一个行动是低成本、可撤回、可现实观察的。
- 用 consultation_case_recorder 生成候选记录，且 validation_result 不再是 unverified。

#### 示例 Payload

```json
{
  "experience_text": "入睡前反复觉得有人在房间里，醒来后仍然紧张。",
  "duration_or_frequency": "近两周每周 3 次，主要发生在熬夜后。",
  "ordinary_triggers": [
    "睡眠不足",
    "咖啡因",
    "近期压力",
    "药物变化。"
  ],
  "red_flags_checked": [
    "自伤风险为否",
    "持续幻听为否",
    "睡眠严重受损需现实支持。"
  ],
  "care_action": "先记录睡眠和压力触发；若持续恶化，建议寻求专业支持。",
  "follow_up_window_days": 14,
  "observed_changes": [
    "夜间醒来次数减少",
    "仍不能排除工作压力影响。"
  ],
  "validation_result": "mixed",
  "reviewer": "internal-reviewer",
  "domain": "sleep_paralysis"
}
```
