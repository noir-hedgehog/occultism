# 发布验收

## 用途

本页说明如何用 `release_gate_runner` 运行发布前一键验收。它把 schema、单元测试、Skill 静态验证、Skill 安装 dry-run、覆盖审计、外部证据入口包、运行时 dry-run、工具 wrapper manifest、工具定义导出、工具定义验证、工具注册表、工具注册表验证、运行时交接包、Web UI surface smoke、回放验证和 Markdown 链接检查统一成一个 JSON 报告。

## 运行方式

```bash
python3 agent-tools/scripts/release_gate_runner.py
python3 agent-tools/scripts/external_evidence_intake_builder.py --codex-home /tmp/mystic-codex-home-preview --format markdown
python3 agent-tools/scripts/agent_runtime_dry_run_runner.py
python3 agent-tools/scripts/agent_tool_wrapper_manifest_builder.py --format markdown
python3 agent-tools/scripts/agent_tool_definition_exporter.py --format openai
python3 agent-tools/scripts/agent_tool_definition_validator.py --format markdown
python3 agent-tools/scripts/agent_tool_registry_builder.py --format markdown
python3 agent-tools/scripts/agent_tool_registry_validator.py --format markdown
python3 agent-tools/scripts/agent_runtime_handoff_builder.py --codex-home /tmp/mystic-codex-home-preview --format markdown
python3 agent-tools/scripts/web_ui_surface_smoke_runner.py --format markdown
```

只运行部分 gate：

```bash
python3 agent-tools/scripts/release_gate_runner.py --gate schema_json --gate markdown_links
```

## Gate 列表

| Gate | 检查内容 |
| --- | --- |
| `schema_json` | 所有 schema JSON 可解析 |
| `codex_skill_blueprint_validator` | Skill 蓝图 frontmatter、引用、工具钩子和索引一致 |
| `codex_skill_installer` | Skill 安装器 dry-run 通过，不写入真实 Codex home |
| `knowledge_coverage_audit` | 流派、知识库、工具三件套、回放和看板覆盖齐全 |
| `external_evidence_intake_builder` | 外部证据入口包可生成，字段、命令和验收标准齐全 |
| `agent_runtime_dry_run_runner` | 代表请求满足 ready/paused/blocked runtime 工具契约 |
| `agent_tool_wrapper_manifest_builder` | 可运行脚本可转成 wrapper 元数据，包含 schema、命令、安全标签 |
| `agent_tool_definition_exporter` | wrapper 元数据可导出为 agent tool definition 和 OpenAI-style function tool |
| `agent_tool_definition_validator` | agent tool definitions 和 OpenAI-style function tools 通过注册形状检查 |
| `agent_tool_registry_builder` | 已验证工具定义可组织成注册顺序、流派/Skill 索引和安全启动工具 |
| `agent_tool_registry_validator` | 工具注册表的注册顺序、Skill 索引、命令、安全标签和 bootstrap 一致 |
| `agent_runtime_handoff_builder` | agent runtime 接入入口、工具链、安全不变量和验证命令可交接 |
| `web_ui_surface_smoke_runner` | 本地 Web UI/API surface 可用代表 payload 通过 HTTP smoke |
| `skill_replay_runner` | 首批 Skill normal/blocked 短请求回放通过 |
| `skill_transcript_runner` | 首批 Skill 多轮 transcript 回放通过 |
| `markdown_links` | Markdown 本地链接不缺失 |
| `unit_tests` | 工具单元测试通过 |

## 判定

- `is_valid: true`：当前自动质量门全部通过。
- `failed_count > 0`：查看 `gates[].errors`，先修失败 gate。
- 自动验收通过后，仍需要人工确认真实匿名 transcript、实际 Skill 安装和内容审校进度。
