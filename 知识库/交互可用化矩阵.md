# 交互可用化矩阵

本页把当前项目的给人入口、API、可程序化执行部分和 Agent/人工接管边界放在同一张表里。它用于判断下一步应该补 UI、补 runtime wrapper、补结构化字段，还是补真实案例/来源材料。

## 摘要

| 指标 | 当前值 |
| --- | --- |
| Surface | 11 |
| API endpoint | 11 |
| 自动化等级 | `agent_handoff_required` 1、`human_readable` 1、`human_review_required` 1、`programmable_now` 5、`requires_real_material` 1、`requires_user_fields` 1、`safe_subset_programmable` 1 |

## 自动化等级

| 等级 | 数量 | 含义 |
| --- | --- | --- |
| `human_readable` | 1 | 给人阅读和导航，不直接执行玄学流程。 |
| `programmable_now` | 5 | 可通过 CLI/API 稳定运行，输出结构化结果。 |
| `safe_subset_programmable` | 1 | 只运行安全白名单子集，并显式标出 skipped/handoff。 |
| `requires_user_fields` | 1 | 需要用户或 UI 补充结构化字段后运行。 |
| `agent_handoff_required` | 1 | 需要 Agent 综合、草稿或审校接管。 |
| `human_review_required` | 1 | 必须人工审校后才能进入正式知识库或案例库。 |
| `requires_real_material` | 1 | 需要真实脱敏材料或来源证据填充。 |

## 验证命令

- 知识库文档站：`curl http://127.0.0.1:8765/api/docs`
- 请求路由与安全分流：`curl -X POST http://127.0.0.1:8765/api/session -H 'Content-Type: application/json' -d '{"request_text":"帮我做一个塔罗三张牌，看看工作状态"}'`
- 问题到范式：`python3 agent-tools/scripts/paradigm_selector.py --text '帮我做一个塔罗三张牌，看看工作状态'`
- 咨询工作单：`python3 agent-tools/scripts/consultation_packet_builder.py --text '帮我做一个塔罗三张牌，看看工作状态'`
- 安全执行子集：`python3 agent-tools/scripts/consultation_execution_runner.py --text '帮我做一个塔罗三张牌，看看工作状态'`
- 结构化工具预览：`curl -X POST http://127.0.0.1:8765/api/tool-preview -H 'Content-Type: application/json' -d '{"mode":"fengshui","payload":{"request_text":"卧室床对门，最近睡不好","space_type":"bedroom","space_description":"卧室床尾正对门","observation_text":"卧室床尾正对门","concerns":["sleep"]}}'`
- Agent 交接：`python3 agent-tools/scripts/consultation_handoff_builder.py --text '帮我做一个塔罗三张牌，看看工作状态'`
- 案例候选记录：`python3 agent-tools/scripts/consultation_case_recorder.py --text '帮我做一个塔罗三张牌，看看工作状态' --follow-up '两天后复盘：建议部分可用' --validation-result mixed --reviewer internal-reviewer`
- 证据矩阵：`python3 agent-tools/scripts/domain_evidence_matrix_builder.py --format markdown`
- 验证 Backlog：`python3 agent-tools/scripts/case_validation_backlog_builder.py --priority P0 --limit 5`
- 采集模板：`python3 agent-tools/scripts/case_validation_template_builder.py --domain fengshui --format markdown`

## 限制

- 此矩阵证明入口、脚本和文档证据存在，不代表真实用户素材或专家审校已经完成。
- programmable_now 只表示本地工具可运行，不表示可以跳过安全分流、输出 lint 或人工审校。
- Web UI 是本地工作台，不包含远程托管、多用户鉴权或生产权限隔离。
