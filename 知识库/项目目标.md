# 项目目标

## 当前目标

推进玄学大典从知识库、Skill、agent-tools 原型进入可用化阶段：

- 以 6 条主干收束 61 个领域，避免继续碎片化扩张。
- 对已建内容做科学化、溯源勘误和神秘强度分层。
- 建立可给人使用的本地 Web UI，先覆盖路由、安全分流、知识入口、工具链和验证状态。
- 建立可程序化调用的本地 API，让外部 agent 或 runtime 可以先接入请求路由和上下文加载。
- 更新 README、仓库描述和发布材料，并同步到 `noir-hedgehog/occultism.git`。

## 当前阶段

当前阶段不是继续铺更多流派，而是把已经建立的体系变成可使用、可审计、可维护的工作台。

## 近期完成标准

- Web UI 可本地启动并返回项目 summary。
- 用户请求可通过 UI/API 路由到对应领域、Skill、SOP、知识卡和初始工具链。
- orange/red 风险请求在 UI/API 层暂停玄学流程。
- README 能让新读者理解项目、启动 UI、运行核心验证。
- GitHub 仓库有清晰 description、初始提交和可复现验证命令。
