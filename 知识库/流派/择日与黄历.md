# 流派知识卡：择日与黄历象征咨询

## 定位

择日与黄历咨询在本知识库中被定位为民俗象征和计划整理工具：帮助用户在现实可行窗口内比较候选日期、理解黄历术语、记录来源和约束。它不提供权威黄历计算，不保证某个日期带来确定结果。

## 常见场景

- 搬家、入宅、乔迁
- 开业、开张、开工、开市
- 婚礼、领证、订婚
- 出行、签约、活动发布
- 家庭内部希望避开某些民俗忌讳

## 核心资料

- 事件类型：做什么事
- 候选日期：用户或现实窗口给出的日期
- 不可用日期：场地、证件、长辈、交通、天气、安全等原因
- 黄历来源：家人口述、黄历截图、地区习惯、网络条目、商业课程
- 术语：宜、忌、冲、煞、黄道吉日、黑道日、建除十二神、值神
- 用户偏好：纪念意义、周末、上午、家人协调、心理安定

## 安全边界

1. 医疗、手术、剖腹产、用药、财务投资、贷款、合同风险、消防和人身安全不能由择日决定。
2. 不把黄历术语写成必然发财、必然顺利、必然灾祸或必须服从。
3. 不把生肖冲合用于指责、排斥或恐吓参与者。
4. 不声称不同黄历、地区、派别和师承一定一致。
5. 没有外部黄历来源时，只能做现实约束和象征偏好排序。

## 解释层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 守门 | 识别医疗、财务、危险仪式和专业替代 | 继续给“吉日保证” |
| 来源 | 标明用户提供的黄历、家人口述或网络说法 | 把来源说成唯一权威 |
| 约束 | 记录候选日期、不可用日期、参与人和场地 | 忽略现实手续与安全 |
| 术语 | 解释宜、忌、冲、煞等含义 | 恐吓或绝对化 |
| 排序 | 现实约束优先，象征偏好次之 | 输出必吉/必凶 |
