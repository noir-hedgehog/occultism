# 易经/周易

## 适用场景

易经类咨询适合问题澄清、阶段判断、卦爻结构和变化关系分析。它更适合作为“如何理解变化”的框架，而不是绝对预测机器。六爻的六亲、六神、世应和用神读盘见 [六爻.md](六爻.md)。

## 核心概念

- 卦：六爻组成的象征结构
- 本卦、变卦、互卦：表示当前结构、变化方向、内在关系
- 爻辞：对具体爻位的象征文本
- 问事原则：一事一问，问题具体，避免反复追问同一问题

## 标准流程

1. 把问题改写为单一、具体、非伤害性问题。
2. 使用 `yijing_casting_method_advisor` 选择或校验起卦方法，并处理重复占问边界。
3. 记录起卦方法与时间。
4. 记录本卦、变爻、变卦。
5. 从卦象、爻位、卦辞爻辞、现实处境分层解释。
6. 给出行动建议和不可判断之处。
