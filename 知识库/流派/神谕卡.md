# 神谕卡

## 概述

神谕卡是开放式卡牌系统的统称，常见形式包括天使卡、动物灵性卡、能量卡、自然母题卡、情绪提示卡等。它通常没有塔罗那样统一的 78 张结构，也没有雷诺曼那样固定的 36 张传统牌组，因此本知识库把它定位为图像、关键词和个人联想的象征反思工具。

## 与塔罗/雷诺曼的区别

- 塔罗有相对稳定的牌组结构、牌序、大小阿尔卡那和牌阵语法。
- 雷诺曼有相对稳定的 36 张牌和相邻组合读法。
- 神谕卡更依赖具体牌组说明、牌面文字、图像元素和用户联想。
- 神谕卡解释不应冒充通用权威牌义，尤其不能替代现实判断或专业建议。

## 常见母题

| 母题 | 常用象征 | 边界 |
| --- | --- | --- |
| 门/入口 | 开始、选择、进入、阈限 | 不承诺机会必然打开 |
| 桥 | 连接、过渡、沟通、跨越 | 不替代关系或合同判断 |
| 种子 | 潜力、培育、耐心、开始 | 不承诺一定成长或成功 |
| 河流 | 流动、顺势、情绪、路径 | 不把顺势写成放弃现实判断 |
| 山 | 挑战、稳定、距离、坚持 | 不写成不可改变的命运 |
| 镜子 | 自省、投射、诚实、看见 | 不读取第三方真实想法 |
| 指南针 | 方向、价值排序、定位、选择 | 不替用户做最终决定 |
| 月亮 | 情绪、周期、潜意识、想象 | 不把情绪当事实或诊断 |
| 太阳 | 清晰、活力、显现、鼓励 | 不承诺成功 |
| 星星 | 希望、愿景、远方目标、灵感 | 不承诺愿望必然实现 |
| 羽毛 | 轻盈、信息、释放、温柔 | 不写成天使命令或灵体证明 |
| 钥匙 | 重点、开启、可行入口、答案感 | 不写成唯一答案 |

## 基本读法

- 单张：本轮焦点、提醒或自我提问。
- 三张：当前主题、支持/阻力、低风险下一步。
- 过去-现在-下一步：只作为叙事整理，不把过去/未来写成事实证明。
- 牌组原文优先：若用户提供牌面文字，先解释文字和图像；若只有模糊牌名，先要求补充。

## 边界

神谕卡在本知识库中不被用于灵体命令、事实调查、命运证明、专业建议或第三方心理读取。涉及合同、治疗、投资、安全、监控、操控、诅咒确认等请求时必须转向现实证据和合格支持。
