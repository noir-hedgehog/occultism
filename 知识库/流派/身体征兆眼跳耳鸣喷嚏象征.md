# 身体征兆/眼跳/耳鸣/喷嚏象征

## 定位

身体征兆类民俗把眼跳、耳鸣、喷嚏、耳热、脸热、手心痒、肉跳等身体感受与时辰、社交想象、财运叙事或吉凶话术相连。Agent 只能把它们作为文化材料、身体照料提醒和低风险反思入口，不把身体感受当作医学事实、灾祸预言或现实决策证据。

## 适用场景

- 用户想了解“左眼跳/右眼跳/耳热/喷嚏”的民俗说法。
- 用户想把一次短暂、低风险的本人身体征兆记录成提醒。
- 用户希望把征兆和睡眠、屏幕、压力、咖啡因、环境刺激等普通背景一起复盘。

## 需要收集的信息

- 征兆类型：眼跳、耳鸣、喷嚏、耳热、脸热、手心痒、肉跳等。
- 身体位置：左眼、右眼、左耳、右耳、脸、手等。
- 时间：日期、时段、发生前后事件。
- 持续与频率：一次、短暂、持续、反复。
- 感受：轻微、疼痛、麻木、视听变化、呼吸变化等。
- 普通背景：睡眠、屏幕、压力、咖啡因、环境刺激、天气、用眼。
- 医疗边界：是否有持续、突发、严重或影响功能的症状。
- 停止条件：记录一次即可，不反复查到安心。

## 常见象征

| 征兆 | 低风险象征 | 边界 |
| --- | --- | --- |
| 左眼跳 | 接收、注意、疲劳、休息提醒 | 不写成发财保证 |
| 右眼跳 | 行动、输出、紧张、节奏提醒 | 不写成灾祸定论 |
| 耳鸣/耳响 | 暂停、安静、信息过载、身体照料 | 持续或单侧优先医疗支持 |
| 耳热 | 被想起、社交感、外界评价 | 不读心 |
| 喷嚏 | 打断、释放、环境刺激、节奏切换 | 不作疾病诊断 |
| 脸热 | 情绪、曝光感、社交压力 | 不证明他人评价 |
| 手心痒 | 交换、欲望、预算提醒 | 不作财运或投资保证 |
| 肉跳 | 紧绷、疲劳、放松提醒 | 不作灾祸或灵异证据 |

## 安全边界

- 医疗红旗优先：持续、突发、严重、单侧、疼痛、视力/听力下降、胸痛、呼吸困难、麻木、晕厥、发烧、孕期、停药或影响功能。
- 不把身体征兆写成确定吉凶、灾祸、死亡、破财、中奖、灵体或诅咒证据。
- 不替第三方身体反应做命运、情绪、人格或关系判断。
- 不给彩票、赌博、投资或重大决定做择时。
- 不鼓励危险身体试验或反复查兆。

## 推荐输出骨架

1. 先确认边界：这只是民俗象征和身体照料记录。
2. 复述用户提供的征兆、时间、位置和普通背景。
3. 给出 1-3 个非决定论象征方向。
4. 给出现实照料清单和医疗红旗提醒。
5. 设置停止条件，避免反复依赖。
