# 命理象征索引

## 用途

本文件给 agent 提供八字/四柱和紫微斗数的基础象征解释骨架。它补足命理咨询中“术语如何安全解释”的中层知识，避免把单一符号写成宿命判断。

此索引不替代排盘、旺衰判断、流派断法或人工命盘审阅。它只用于文化解释、自我理解和低风险行动提示。

## 覆盖范围

| 类别 | 示例 | 用途 | 边界 |
| --- | --- | --- | --- |
| 天干 | 甲、乙、丙、丁 | 描述表达方式、行动质地和资源倾向 | 不单独判断命格强弱 |
| 地支 | 子、丑、寅、卯 | 描述阶段、节奏、环境和隐含条件 | 不单独判断吉凶 |
| 十神 | 正官、七杀、食神、偏财 | 描述关系、资源、压力、输出和支持结构 | 不写成职业、婚姻、财富定论 |
| 紫微宫位 | 命宫、官禄宫、夫妻宫 | 描述命盘问题领域和观察角度 | 不替代现实关系、职业、健康判断 |
| 紫微主星 | 紫微、天机、太阳、破军 | 描述宫内象征主题和行动风格 | 不把星曜贴成终身人格标签 |

## 安全解释顺序

1. 先确认用户请求已通过 `bazi_ziwei_intake_guard`。
2. 若涉及精确出生资料，先记录隐私和同意边界。
3. 说明术语类别：天干、地支、十神、宫位或星曜。
4. 用 2-4 个关键词描述象征主题。
5. 连接用户焦点：事业、关系、自我理解、阶段复盘。
6. 提出可观察信号，不做确定预测。
7. 给低风险行动提示。
8. 用 `mystic_output_lint` 检查最终草稿。

## 十神解释边界

| 十神 | 可说 | 避免 |
| --- | --- | --- |
| 比肩/劫财 | 自主性、同辈压力、资源边界 | “一定被朋友拖累” |
| 食神/伤官 | 表达、创造、突破规则 | “必然叛逆/不服管” |
| 正财/偏财 | 资源管理、机会、现实经营 | 投资、贷款、发财保证 |
| 正官/七杀 | 职责、压力、竞争、行动魄力 | 断言官非、灾祸或必须服从 |
| 正印/偏印 | 学习、支持、保护、非常规理解 | 把敏感写成精神问题或命定孤独 |

## 紫微宫位解释边界

| 宫位 | 可说 | 避免 |
| --- | --- | --- |
| 命宫 | 自我呈现和惯性模式 | 终身人格标签 |
| 夫妻宫 | 关系互动和投射 | 断言伴侣想法或婚姻必然 |
| 财帛宫 | 资源习惯和收入方式 | 投资/借贷建议 |

| 官禄宫 | 职责、长期角色、工作路径 | 替用户辞职或职业定局 |
| 福德宫 | 休息、价值感、精神生活 | 把情绪困扰命定化 |
