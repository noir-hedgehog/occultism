# 易经 384 爻索引

## 用途

本索引用于补足 [易经64卦速查](易经64卦速查.md) 的动爻层。它提供 64 卦 × 6 爻的结构化解释骨架：爻位阶段、阴阳属性、位置关系、变卦方向和现实行动提示。

当前版本是现代咨询索引，不是《周易》原文爻辞，也不是传统注疏资料库。agent 必须在输出中保留这个来源等级，避免把骨架误说成经典原文。

## 六爻位置

| 爻位 | 阶段 | 关注点 | 行动提示 |
| --- | --- | --- | --- |
| 初爻 | 起点 | 根基、潜动、尚未外显的开端 | 先稳住基础，不急于扩大动作 |
| 二爻 | 内在承接 | 配合、承载、可持续性 | 从日常节奏和可持续配合入手 |
| 三爻 | 临界压力 | 内外转换、躁进、试探风险 | 放慢推进，评估代价和支持 |
| 四爻 | 外部连接 | 资源连接、权责接近、分寸 | 小步试探，确认反馈 |
| 五爻 | 主位决策 | 主责、标准、整合能力 | 明确责任和可承担的选择 |
| 上爻 | 阶段尾声 | 过度、收束、余波 | 及时收尾，避免拖旧局 |

## 阴阳与位置关系

| 组合 | 读法 |
| --- | --- |
| 阳爻居阳位 | 动力和位置较一致，防止过刚 |
| 阴爻居阴位 | 承接和位置较一致，防止过柔 |
| 阳爻居阴位 | 行动力处在承接位置，宜柔化表达 |
| 阴爻居阳位 | 承接力处在主动位置，宜补足决断 |

## 解读顺序

1. 先读本卦：它描述当前处境和主主题。
2. 再读动爻：它描述变化发生在哪个阶段、位置和行动层。
3. 再读变卦：它描述变化后的趋势或新局面。
4. 最后落地：把象征转成一个可观察、低风险、可执行的现实动作。

## 示例

| 输入 | 结构化读法 |
| --- | --- |
| 乾卦初爻动 | 初爻是起点，阳爻居阳位；由乾的开创主动，转向姤的相遇与边界。重点不是“必有相遇”，而是主动起势后会接触新诱因，需要守边界。 |
| 既济三爻动 | 三爻是临界压力，阳爻居阳位；由既济的已成与维护风险，转向屯的困难开局。重点是完成后若跨界躁进，可能回到混乱开端，需要复盘顺序。 |
| 坤五爻动 | 五爻是主位决策，阴爻居阳位；由坤的承载顺势，转向比的联盟归属。重点是承接者进入主责位，需要明确合作标准。 |
