# 流派知识卡：卢恩符文

## 定位

卢恩符文在本知识库中只作为象征性自我反思、文化学习和问题整理工具。当前工具索引采用常见 Elder Futhark 名称作为安全解释层，不把符文结果写成事实证明、神谕、诅咒确认、专业建议或最终决定。

## 核心对象

- 符文层：Fehu、Uruz、Thurisaz、Ansuz、Raidho 等 Elder Futhark 符号
- 牌阵层：单符、三符、过去/现在/未来、自定义位置
- 方法层：用户已有抽取、手动记录、来源说明、未知符文确认
- 现实层：证据、沟通、边界、成本、风险承受度、专业意见
- 停止层：反复抽取、恐惧升级、专业替代、第三方操控

## 安全边界

1. 不把符文结果写成事实、诊断、预测、诅咒确认或最终决定。
2. 医疗、法律、财务、安全、紧急问题必须转向现实专业支持。
3. 不用符文判断第三方隐私、真实想法、人品或是否会被操控。
4. 不确认附身、黑魔法、诅咒、被害或超自然伤害。
5. 对反复抽取、越抽越焦虑、抽到满意为止的请求必须降级或暂停。

## 解读层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 边界层 | 说明符文只作象征反思和文化解释 | 声称符文证明事实 |
| 问题层 | 把 yes/no 或命运问题改成资源、阻力和下一步 | 替用户决定 |
| 记录层 | 记录符文、位置、来源和缺失字段 | 补造抽取结果 |
| 符号层 | 用关键词、位置和现实语境组合 | 预言、恐吓、诊断 |
| 行动层 | 给低风险核查和停止追问条件 | 反复抽到满意 |

## 常用符文提示

- Fehu：资源、流动、管理
- Uruz：韧性、动力、恢复
- Thurisaz：边界、阻力、门槛
- Ansuz：讯息、语言、学习
- Raidho：旅程、路线、协调
- Gebo：互惠、交换、关系平衡
- Algiz：保护、警觉、界限
- Dagaz：破晓、转换、重新看见

## 输出原则

- 先现实证据，后象征提示。
- 每枚符文都绑定一个位置、一个现实问题和一个低风险行动。
- 未知符文先要求确认拼写或来源，不强行解释。
- 用户焦虑、依赖或恐惧时，优先稳定、休息、可信任支持或专业支持。
