# 流派知识卡：解梦与梦境象征

## 定位

解梦在本知识库中只作为梦境象征咨询：帮助用户整理梦境素材、醒后情绪、现实背景和个人联想。它不证明梦境具有客观预言力，也不替代心理健康、医疗或睡眠问题评估。

## 核心对象

- 梦境片段：场景、人物、动作、物体、颜色、时间感
- 醒后感受：恐惧、悲伤、愤怒、轻松、困惑
- 现实背景：近期压力、关系、变化、疲劳、创作目标
- 常见符号：水、追赶、坠落、掉牙、考试、房子、蛇、死亡、飞行、迷路
- 用户目标：降低不安、情绪整理、文化学习、创作启发

## 安全边界

1. 不把梦解释成死亡、疾病、灾祸、发财、复合或背叛的确定预告。
2. 不把梦写成鬼神、诅咒、附身或外部操控的证据。
3. 不做心理诊断，不替代创伤、睡眠或精神健康支持。
4. 反复噩梦、严重失眠、自伤想法、幻觉、现实功能受损时，应暂停解梦并建议现实支持。
5. 对第三方梦境人物只谈用户自己的感受和关系模式，不宣称对方真实想法。

## 解读层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 素材记录 | 复述用户提供的梦境，不补写细节 | 编造隐含剧情 |
| 情绪层 | 命名醒后感受和强度 | 把感受写成事实 |
| 符号层 | 查询常见象征，并询问个人联想 | 一符号一答案 |
| 现实锚点 | 连接近期压力、关系、变化或疲劳 | 把梦当成外部证据 |
| 行动层 | 给低风险记录、沟通、休息或整理建议 | 仪式化、恐吓或专业替代 |

## 常见符号提示

- 水：情绪流动、承载、边界
- 被追：压力、回避、紧迫感
- 坠落：失控感、不稳定、缺少支撑
- 掉牙：表达、形象、变化焦虑
- 考试迟到：评估压力、准备感、期限
- 房子/房间：自我空间、边界、安全感
- 蛇：警觉、本能、变化；需先询问个人联想
- 死亡/葬礼：结束、告别、转变；不能写成死亡预告
- 飞行：自由、视角、脱离限制
- 迷路：方向感、信息缺口、选择压力

## 输出原则

- 使用“可能象征”“可以当作”“更安全的读法是”等措辞。
- 先把恐惧降级，再给解释。
- 每次解梦至少给一个现实锚点和一个低风险行动。
- 若信息不足，优先补问情绪和现实背景。
