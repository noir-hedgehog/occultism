# 流派知识卡：六爻占问

## 适用场景

- 用户希望用六爻框架整理单一问题的变化结构、阻力、资源和下一步。
- 用户已用铜钱、手动起卦或外部工具得到六爻盘，希望解释六亲、六神、世应、用神和爻位。
- 用户想做文化学习、问题澄清、象征反思，而不是确定性预测。

## 不适用场景

- 医疗、法律、财务、危机、人身安全、投资、诉讼、用药等专业或高风险决策。
- 反复追问同一问题，或把多个问题合并为一卦。
- 要求窥探、控制、诅咒、报复他人，或未经同意分析第三方隐私。
- 要求 agent 直接保证成败、疾病、财富、婚恋、寿命或灾祸结局。

## 核心概念

- 一事一问：六爻读盘必须先收束问题。
- 本卦/变卦/动爻：借用易经卦爻结构记录当前结构和变化倾向。
- 六亲：父母、兄弟、子孙、妻财、官鬼，用作不同事项的象征观察点。
- 六神：青龙、朱雀、勾陈、腾蛇、白虎、玄武，用作表达、阻滞、风险和信息风格提示。
- 世应：世爻偏本人或主位，应爻偏对方、环境或外部回应。
- 用神：根据问题取主要观察点；不同派别和问题类型可能有差异。

## 需要收集的信息

- 原始问题和安全分级。
- 是否一事一问、是否反复占问。
- 起卦方法、时间、时区、外部卦盘来源。
- 本卦、变卦、动爻、世应、六亲、六神和用神取法。
- 用户希望的输出焦点：关系、合作、项目、失物、学习、状态等。

## 标准流程

1. 运行通用 intake，识别六爻领域和风险等级。
2. 运行易经问题守门，确认一事一问、非重复、非高风险。
3. 若缺卦盘，询问用户是否提供外部卦盘或使用已有易经起卦工具生成结构；不得编造盘式。
4. 用 `liuyao_chart_recorder` 记录取用逻辑：问题焦点、用神、世应、动爻、六亲、六神和资料来源。
5. 用 `liuyao_focus_selector` 生成候选用神、世应观察点和读盘顺序；没有完整盘式时只做候选取用，不做爻位解释。
6. 使用六爻术语查询工具解释六亲、六神、世应/用神角色和爻位。
7. 将符号转成现实映射：证据、风险、资源、沟通边界和低风险行动。
8. 输出前检查确定性、恐吓、专业替代、操控他人和隐私越界。

## 输出格式

```text
安全分级：
问题守门：
起卦/盘式来源：
盘式记录：
取用逻辑：
六亲/六神/世应：
变化结构：
现实映射：
可观察信号：
低风险建议：
限制与提醒：
```

## 常见误区

- 不问问题类型就直接定用神。
- 把白虎、官鬼、玄武等术语写成恐吓或灾祸断言。
- 把六亲字面化，例如把“妻财”直接等同于某个女性或财富结果。
- 混用派别规则却不说明来源。
- 对医疗、投资、法律、关系操控做确定判断。

## 安全边界

- 不替代医疗、法律、财务、心理健康、职业或紧急安全建议。
- 不输出“必成/必败/必分/必死/必发财/一定有灾”等决定论句式。
- 不分析未经同意的第三方隐私。
- 涉及危机、现实危险、持续失眠、幻听幻视或自伤他伤时，先暂停占问并转现实支持。

## 已工具化

- 六亲、六神、世应/用神和爻位象征索引。
- 六爻盘式记录器：记录本卦、变卦、动爻、世应、六亲、六神和取用逻辑。
- 六爻用神选择器：按问题类型给出候选用神，映射到世应、动爻和已记录爻位，并保留派别差异说明。
