# 塔罗牌阵案例与逆位策略

## 用途

本文件给 agent 提供塔罗解读的中层规则：先让牌阵拆问题，再让单牌进入牌位，最后把正逆位和牌间关系转成现实行动。它补足 [塔罗牌义速查](塔罗牌义速查.md) 的单牌层，避免直接把关键词拼成结论。

## 牌阵案例

| 场景 | 推荐牌阵 | 读法重点 | 避免 |
| --- | --- | --- | --- |
| 今日提醒 | 单张聚焦 | 当前最值得注意的状态和一个小行动 | 写成当天必然发生的事件 |
| 工作卡住 | 三张状态牌阵 | 现状、阻碍、建议三层递进 | 把阻碍归因成某个人必然作恶 |
| 二选一 | 二选一路径 | A/B 各自条件、提醒和共同原则 | 直接替用户决定 |
| 关系复盘 | 关系镜像 | 我方状态、对方可能状态、互动模式、边界建议 | 确定断言对方想法或未来行为 |
| 重大决定焦虑 | 决策落地 | 真正关切、可用资源、主要风险、下一步 | 替代医疗、法律、财务等专业判断 |

## 正逆位策略

| 情况 | 推荐读法 | 输出提醒 |
| --- | --- | --- |
| 无逆位 | 能量较顺畅、外显或已经可见 | 仍要检查现实限制 |
| 单张逆位 | 局部卡点、内化、过度或延迟 | 必须结合牌位，不直接说坏 |
| 多张逆位 | 系统性阻滞、节奏不稳、需要减压 | 降低确定性，优先建议澄清和调整 |
| 全部逆位 | 可能不适合强推结果，需要先整理状态 | 不要恐吓，不要扩大成灾祸 |
| 逆位落在建议位 | 建议不是“去做阴影”，而是修正对应过度或缺失 | 用“减少/暂停/澄清/补足”表达 |

## 牌间互动

- 大阿尔卡那多：适合谈阶段主题、价值选择、成长课题，但必须落到具体行动。
- 同一花色多：该元素主题优先。权杖看行动，圣杯看感受，宝剑看沟通判断，星币看资源现实。
- 牌位和牌义冲突：先说明冲突本身，例如“建议位出现停顿牌，提醒不是硬推，而是换视角”。
- 关系牌阵：对方牌只写“可能状态”，重点回到用户能做的边界、沟通和观察。
- 高风险问题：即使牌面积极，也不能鼓励贷款、停药、违法、跟踪或自伤。

## 三张状态牌阵示例骨架

| 牌位 | 示例牌 | 解读骨架 |
| --- | --- | --- |
| 现状 | 愚者正位 | 事情处在新起点，用户可能需要探索，但要看准备是否足够。 |
| 阻碍 | 宝剑三逆位 | 沟通或失望仍在内化，阻碍不是单一事件，而是未处理的语言和感受。 |
| 建议 | 星币国王正位 | 下一步落到资源、节奏、边界和稳定执行，而不是只靠情绪推动。 |

## 二选一示例骨架

| 牌位 | 读法 |
| --- | --- |
| A 方案状态 | 描述 A 的当前资源和动能。 |
| A 方案提醒 | 指出 A 需要验证的风险。 |
| B 方案状态 | 描述 B 的当前资源和动能。 |
| B 方案提醒 | 指出 B 需要验证的风险。 |
| 共同建议 | 不替用户选边，而是抽出决策标准和下一步信息收集动作。 |
