# 流派知识卡：占星/星盘象征咨询

## 适用场景

- 用户希望了解星座、太阳/月亮/上升、宫位、相位等符号的象征含义。
- 用户已从外部排盘工具获得星盘字段，希望把它们转成自我观察、关系沟通或职业倾向的反思。
- 用户想做文化学习、符号解释、低风险自我整理，而不是要求确定性预测。

## 不适用场景

- 医疗、法律、财务、心理危机、投资、婚育、寿命、灾祸等专业或高风险决策。
- 要求判断“某人一定爱我/不爱我”“是否绝配”“什么时候发财”“一定会发生什么”。
- 未经同意分析第三方精确出生资料、未成年人星盘，或保存可识别出生资料。
- 要求 agent 直接生成精确星盘、行运、合盘结论，且没有可靠排盘来源。

## 核心概念

- 星座：描述表达风格和主题色彩，不等于人格定型。
- 行星：描述心理功能或生命议题，例如太阳偏向意志，月亮偏向情绪需求。
- 宫位：描述议题发生的生活领域，例如十宫偏向公众角色和事业结构。
- 四轴点：上升、下降、天顶、天底，用作呈现、关系、公众角色和根基的象征入口。
- 相位：描述两个符号之间的关系语言，例如合相聚焦、刑相摩擦、拱相顺流。

## 需要收集的信息

- 用户目标：文化学习、自我理解、关系沟通、职业反思或日常提醒。
- 已知星盘字段：星座、行星、宫位、相位；优先让用户提供外部排盘结果。
- 资料来源：外部排盘工具、用户手动输入、仅知道太阳星座。
- 同意状态：是否本人资料；若涉及第三方，是否取得明确同意。
- 风险筛查：是否涉及专业替代、危机、操控、恐吓或宿命论诉求。

## 标准流程

1. 先运行通用 intake，识别占星领域、用户意图和风险等级。
2. 对精确出生时间、地点和第三方资料做最小化处理；无同意时只做匿名文化解释。
3. 声明不生成星盘、不做决定论预测，只解释用户提供的符号或公开常识。
4. 使用占星符号查询工具解释星座、行星、宫位、四轴点或相位。
5. 将符号转为现实观察：可见行为、情绪需求、沟通模式、环境线索和低风险行动。
6. 输出前检查是否出现确定性、恐吓、专业替代、操控他人或隐私越界。

## 输出格式

```text
安全分级：
资料来源与同意：
问题重述：
符号清单：
象征解释：
现实映射：
可观察信号：
低风险建议：
限制与提醒：
```

## 常见误区

- 把太阳星座等同于完整人格。
- 用合盘替用户判断对方真实意图或关系必然结局。
- 把行运写成灾祸预告或财富保证。
- 混用不同占星体系却不说明来源、算法和限制。
- 对第三方精确出生资料做未经同意的分析。

## 安全边界

- 不做医疗诊断、用药建议、投资建议、法律判断、危机处置替代。
- 不输出“绝配”“必分”“命中注定”“必发财”“一定有灾”等决定论句式。
- 不保存身份证、手机号、真实姓名、精确出生资料和第三方隐私。
- 涉及焦虑、失眠、幻听幻视、自伤他伤等信号时，先转向现实支持和专业帮助。

## 后续可工具化的部分

- 星盘字段记录器：只记录用户提供的外部星盘字段、来源和同意状态。
- 相位组合解释器：把行星、星座、宫位、相位组合成解释骨架。
- 合盘/比较盘边界守门：重点拦截操控、窥探和决定论关系判断。
- 真实匿名占星 transcript 回放集。
