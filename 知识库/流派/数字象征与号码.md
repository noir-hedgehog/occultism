# 流派知识卡：数字象征与号码

## 定位

数字象征、数字能量、生命灵数和号码咨询在本知识库中只作为文化联想与偏好整理：帮助用户比较数字片段、读音、记忆度和个人感受。它不证明数字会改变命运、保证财富、决定关系或替代现实专业判断。

## 核心对象

- 数字：0-9、重复数字、尾号组合
- 使用场景：手机号尾号、车牌号、门牌号、生日/生命灵数、幸运数字
- 现实条件：隐私、价格、可用性、记忆度、读音、业务识别、家人接受度
- 用户目标：文化学习、偏好排序、降低焦虑、选择辅助

## 安全边界

1. 不收集或展示身份证、银行卡、验证码、密码、完整手机号等敏感标识。
2. 不承诺发财、转运、复合、录用、健康或命运改变。
3. 不通过号码判断第三方人品、隐私、职业适配或性格。
4. 不把未成年人号码或生日写成命运/性格定论。
5. 投资、医疗、法律、合同和安全问题必须转向现实专业判断。

## 解读层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 隐私层 | 只处理脱敏尾号或非敏感数字 | 要求完整敏感号码 |
| 场景层 | 区分手机号、车牌、门牌、生命灵数 | 混成单一命运体系 |
| 现实层 | 先比较价格、可用性、记忆度和读音 | 象征压过现实条件 |
| 象征层 | 解释数字文化联想和个人偏好 | 发财/倒霉保证 |
| 行动层 | 给低风险选择和记录建议 | 恐吓、依赖、专业替代 |

## 常见符号提示

- 0：留白、起点、循环
- 1：开始、独立、行动
- 2：关系、配合、平衡
- 3：表达、创意、扩展
- 4：结构、秩序、稳定；不恐吓谐音
- 5：变化、自由、试错
- 6：照顾、责任、顺滑；不保证必顺
- 7：探索、内省、分析
- 8：资源、经营、可见成果；不保证发财
- 9：完成、愿景、释放

## 输出原则

- 现实条件优先，数字象征次之。
- 使用“可以象征”“如果你喜欢这个联想”“现实上仍要看”等措辞。
- 只比较脱敏片段。
- 若用户把数字当成决定命运的唯一依据，先降级为偏好和现实约束。
