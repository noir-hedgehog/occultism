# 流派知识卡：求签与签文

## 定位

求签、解签、观音签、月老签和各类灵签在本知识库中只作为签文象征咨询：帮助用户记录来源、理解隐喻、整理现实问题和低风险行动。它不证明结果必然应验，也不替代医疗、法律、财务、人身安全或心理健康支持。

## 核心对象

- 签文素材：签号、签等、签诗、解曰、故事典故、关键词
- 来源：寺庙/宫观、书籍签本、应用、小程序、用户已抽、模拟抽签
- 主题：关系、事业、学业、家庭、搬迁、文化学习
- 用户目标：降低焦虑、整理选择、理解民俗、写作素材

## 安全边界

1. 不把签文写成保证、命令、灾祸预告或惩罚。
2. 不用签文替代医生、律师、财务顾问、报警或安全计划。
3. 不断定第三方真实想法、复合结局、正缘、发财、录用或考试结果。
4. 不鼓励反复抽签、抽到满意、每天依赖签文做决定。
5. 模拟抽签必须说明是模拟和娱乐/反思，不等同寺庙签。

## 解读层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 来源层 | 记录签文来源、版本、签号、签等 | 伪造来源或权威 |
| 字面层 | 提取签诗关键词和明显隐喻 | 编造签文全文 |
| 象征层 | 解释提醒、资源、阻力、等待或行动 | 一句签文定终身 |
| 现实层 | 对应用户的一事一问和现实证据 | 用签文替代事实 |
| 行动层 | 给低风险下一步和补问 | 恐吓、命令、操控 |

## 常见符号提示

- 上上签/大吉：资源较顺、鼓励推进；不保证必成。
- 上签/吉签：条件相对可用；仍需现实验证。
- 中签/平签：平衡、等待、信息不足；适合稳住节奏。
- 下签/不利签：阻力和风险暴露；适合风险管理，不恐吓。
- 月老签：关系期待、沟通、边界；不判断正缘或复合。
- 事业签：资源、阻力、时机、行动；不保证录用或发财。

## 输出原则

- 使用“可作为提醒”“更安全的读法”“现实上仍需确认”等措辞。
- 好签落到行动，差签落到风险管理。
- 来源不明时先标注不确定性。
- 每次至少给一个现实锚点和一个可控行动。
