# 风水理气派别边界

## 定位

本文件用于帮助 agent 处理玄空飞星、八宅、三合/三元、择日等理气派别请求。它不提供完整排盘法，而是定义进入理气解释前必须确认的来源、字段和安全边界。

## 派别速览

| 派别/层级 | 常见关键词 | 需要先确认 | 安全输出范围 |
| --- | --- | --- | --- |
| 形法 | 门冲、梁压、明堂、动线、采光 | 可见事实、空间类型、主要困扰 | 动线、光线、收纳、隐私和低风险调整 |
| 八卦方位 | 东南、西南、正北、九宫方位 | 方位来源，或标注为用户估计 | 传统象征和现实观察问题 |
| 玄空飞星 | 玄空、飞星、九运、山星、向星、五黄、二黑 | 派别、坐向/朝向、方位来源、建造/入住/运期或外部盘 | 方法受限的象征解释，不断财富疾病 |
| 八宅 | 八宅、东四命、西四命、命卦、宅命 | 坐向/朝向、方位来源、宅命或使用者命卦来源 | 空间偏好和动线建议，不贴人生命格标签 |
| 三合/三元 | 来龙、水法、砂水、三合、三元 | 地形/水路上下文、资料来源和复述范围 | 文化或方法说明，避免实地断法 |
| 择日 | 入宅、动土、开业日、搬家日 | 事件类型、候选日期范围、现实安排限制 | 文化解释和提醒，不替代安全/法律/工程安排 |

## 守门规则

1. 先用 `fengshui_school_guard` 判断请求是形法、八卦象征还是理气派别。
2. 理气前提缺失时，不生成盘、不补字段、不下吉凶结论。
3. 检测到多个派别时，要求用户选择一个方法，或退回形法审视。
4. 涉及破财、生病、婚恋、灾祸、承重、燃气、电路、消防时，先转现实边界。
5. 所有建议仍应低成本、可逆、非危险，并通过 `mystic_output_lint`。

## 安全表达

- “你给的字段不足以做玄空飞星判断；我们可以先记录坐向、方位来源和运期，或退回可见空间审视。”
- “五黄、二黑等术语不能直接写成疾病或破财保证，只能作为传统象征里的压力提醒。”
- “八宅和玄空是不同方法，不能混成一个确定结论；请先选择一种规则。”

## 禁用表达

- “这个方位一定破财/生病。”
- “不需要坐向也能排飞星。”
- “八宅和玄空都一样，我综合断一下。”
- “拆墙、改燃气、封窗就能化煞。”
