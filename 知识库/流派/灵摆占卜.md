# 流派知识卡：灵摆占卜

## 定位

灵摆、摆锤和 pendulum 在本知识库中只作为象征性自我反思、偏好澄清和仪式化记录工具。它不证明外部事实，不读取第三方真实想法，不替用户做医疗、法律、财务、安全或关系决定。

## 核心对象

- 工具：灵摆、摆锤、吊坠、手持悬垂物
- 方法层：校准、问题改写、摆动记录、暂停条件
- 摆动层：顺时针、逆时针、前后、左右、静止、不明确
- 答案层：yes、no、maybe，只作倾向提示
- 现实层：证据、沟通、边界、时间成本、风险承受度、专业意见

## 安全边界

1. 不把灵摆结果写成事实、诊断、预测或最终决定。
2. 医疗、法律、财务、安全、紧急问题必须转向现实专业支持。
3. 不用灵摆判断第三方隐私、真实想法、人品或是否会被操控。
4. 不确认附身、邪灵、诅咒、被害或超自然伤害。
5. 对反复追问、越问越焦虑、问到满意为止的请求必须降级或暂停。

## 解读层次

| 层次 | 做法 | 避免 |
| --- | --- | --- |
| 边界层 | 说明灵摆只作象征反思 | 声称结果证明事实 |
| 问题层 | 把 yes/no 改成证据和偏好问题 | 替用户决定 |
| 校准层 | 记录本次 yes/no/不确定约定 | 事后强行解释 |
| 摆动层 | 用倾向、暂缓、比较、缺证据语言 | 预言、诊断、恐吓 |
| 行动层 | 给低风险核查和停止追问条件 | 反复问到满意 |

## 常见摆动提示

- 顺时针：确认、聚焦、推进、整合
- 逆时针：回看、松动、暂缓、排除
- 前后：靠近、试探、往返、需要更多信息
- 左右：分歧、比较、边界、选择未定
- 静止：暂停、问题不清、环境或状态不适合继续
- 不明确：信号混杂，需要改写问题或停止本轮

## 输出原则

- 先现实证据，后象征提示。
- yes/no 只能写成“当前象征倾向”，不能写成事实。
- 每次解读都给一个现实核查动作和一个停止追问条件。
- 用户焦虑或依赖时，优先稳定、休息、找可信任的人或专业支持。
