# 八字与紫微斗数

## 适用场景

八字、四柱和紫微斗数适合做自我理解、阶段复盘、倾向整理和低风险行动提示。它们可以作为一种传统象征语言，帮助用户整理“我在哪些模式里反复行动”“当前阶段有哪些压力与资源”。

## 不适用场景

- 判断寿命、死期、灾祸、疾病、婚育必然结果
- 替代医疗、法律、财务、心理健康等专业判断
- 未经同意分析第三方命盘
- 给未成年人贴终身标签
- 用命盘控制他人、制造恐惧或要求重大不可逆决策

## 核心概念

- 八字/四柱：以年、月、日、时四柱及天干地支组织出生资料。
- 紫微斗数：以命盘宫位、主星、辅曜和四化等组织象征结构。
- 大运/流年：阶段性象征框架，只能作为复盘和观察线索。
- 用神、格局、宫位、星曜：不同派别解释差异很大，需要标注方法来源。
- 干支、十神、宫位、星曜索引：只提供象征语言和解释骨架，不替代排盘和流派断法。

## 需要收集的信息

- 是否为本人资料，若为第三方是否已获得同意
- 出生日期、出生时间、出生地点、历法类型
- 是否需要真太阳时或派别特定校正
- 用户分析焦点：自我理解、事业、关系、阶段复盘等
- 用户不希望被记录或输出的隐私字段

## 标准流程

1. 使用通用 intake 做安全分级。
2. 使用 `bazi_ziwei_intake_guard` 检查出生资料、隐私同意和高风险提问。
3. 若 `can_continue_mingli` 为 `false`，先处理安全、专业支持、隐私同意或问题改写。
4. 明确流派：八字、紫微斗数，或只做命理文化解释。
5. 若用户询问派别差异或混用，使用 `mingli_school_reference` 说明子平/传统/现代综合/三合/四化/中州的字段差异和方法边界。
6. 使用 `bazi_ziwei_chart_record` 标注排盘来源、历法、时区、真太阳时策略和派别限制。
7. 使用 `mingli_symbol_lookup` 或人工等价规则查询干支、十神、宫位和星曜解释骨架。
8. 分层解释：资料记录、象征结构、现实映射、可验证观察、低风险行动。
9. 使用 `mystic_output_lint` 检查宿命论、恐吓和专业替代措辞。

## 输出格式

```text
安全分级：
隐私与同意：
资料完整度：
问题重述：
方法范围：
象征结构：
现实映射：
可观察信号：
低风险建议：
限制与提醒：
```

## 常见误区

- 把命盘解释成不可改变的命运判决。
- 未经同意输入伴侣、前任、同事、孩子的精确出生资料。
- 直接根据命盘建议离婚、辞职、投资或停药。
- 混用八字、紫微、占星、姓名学术语而不说明来源。
