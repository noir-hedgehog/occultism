# 流派知识卡：梅花易数

## 适用场景

- 用户希望用梅花易数框架整理单一问题的主体、对象、触发点、过程和变化方向。
- 用户已通过报数、时间、外应或外部工具得到卦象字段，希望解释体卦、用卦、互卦、变卦、动爻和五行关系。
- 用户想做文化学习、取象练习、低风险自我反思，而不是确定性预测。

## 不适用场景

- 医疗、法律、财务、危机、人身安全、投资、诉讼、用药等专业或高风险决策。
- 反复追问同一问题，或把多个问题合并成一次起卦。
- 要求用外应恐吓、确认超自然伤害、窥探或操控他人。
- 要求 agent 凭空编造数字、时间、外应或盘式来源。

## 核心概念

- 体卦：主体、本方、承受点或用户自身处境。
- 用卦：对象、事件、外部条件或问题所指之事。
- 互卦：中间过程、内在牵连和隐藏结构。
- 变卦：变化方向和后续倾向。
- 动爻：触发变化的层级和行动焦点。
- 外应：环境中的可见线索；必须先当作观察材料，不当作超自然确认。
- 五行生克：体用之间的资源、压力、消耗和可控性关系。

## 需要收集的信息

- 原始问题和安全分级。
- 是否一事一问、是否反复占问。
- 起卦来源：报数、时间、外应、方位、外部工具或手动记录。
- 本卦、互卦、变卦、动爻、体卦、用卦和体用生克关系。
- 用户希望的输出焦点：项目、关系、沟通、学习、失物、状态等。

## 标准流程

1. 运行通用 intake，识别梅花易数领域和风险等级。
2. 运行易经问题守门，确认一事一问、非重复、非高风险。
3. 若缺起卦来源，请用户提供数字、时间、外应记录或外部卦盘；不得编造。
4. 用 `meihua_omen_recorder` 记录外应的事实、来源、时间关系和可验证边界。
5. 用 `meihua_casting_recorder` 记录起卦来源、体用、动爻、互卦、变卦和五行关系。
6. 用 `meihua_relation_interpreter` 把有效体用生克关系转成资源、压力、现实证据问题和低风险行动。
7. 使用梅花术语查询工具解释体用、外应、动爻、五行生克和八卦象征。
8. 将象征转成现实映射：可见事实、资源、阻力、沟通边界和低风险行动。
9. 输出前检查确定性、恐吓、专业替代、操控他人和隐私越界。

## 输出格式

```text
安全分级：
问题守门：
起卦来源：
起卦记录：
体用与动爻：
互卦/变卦：
取象解释：
现实映射：
可观察信号：
低风险建议：
限制与提醒：
```

## 常见误区

- 把偶然外应写成天意或灾祸确认。
- 没有数字/时间/外应来源就直接起卦。
- 把体用生克写成绝对成败。
- 混用派别算法却不说明来源。
- 用梅花替代医疗、投资、法律或危机处理。

## 安全边界

- 不替代医疗、法律、财务、心理健康、职业或紧急安全建议。
- 不输出“必成/必败/必分/必有灾/必发财”等决定论句式。
- 不把外应解释成超自然伤害确认。
- 涉及危机、现实危险、持续失眠、幻听幻视或自伤他伤时，先暂停占问并转现实支持。

## 已工具化

- 体用/外应/五行关系/八卦象征索引。
- 梅花起卦记录器：记录数字、时间、外应来源、体用、动爻、互卦和变卦。
- 梅花外应观察记录器：先记录事实、来源和时间关系，再进入象征提示，阻断恐吓式外应解释。
- 梅花体用关系解释器：把五行生克关系转成资源、压力、证据问题和低风险行动。
