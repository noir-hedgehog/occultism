# 跨流派深度案例集

## 用途

本文件给 agent 和维护者提供跨流派安全案例：遇到相似用户请求时，先看案例的安全解释步骤、示例表达和禁用表达，再调用对应工具。它与 [跨流派深度解读矩阵](跨流派深度解读矩阵.md) 配套使用。

配套工具：`symbolic_case_library`；塔罗三张以上案例可继续调用 `tarot_combination_planner`，风水阳宅场景可继续调用 `fengshui_yangzhai_case_library`。

| 仪式安全 | 3 | 密闭明火、搬家安定、商业水晶转运声明 |

## 使用方式

```bash
python3 agent-tools/scripts/symbolic_case_library.py --domain tarot --query 工作
python3 agent-tools/scripts/symbolic_case_library.py --domain ritual --scenario blocked_then_safe
python3 agent-tools/scripts/symbolic_case_library.py --query 第三方出生资料
```

## 维护规则

- 新增案例必须包含：安全解释步骤、示例表达、禁用表达、推荐工具链、审查问题。
- 示例表达只能作为风格边界，不得直接当作完整最终答案。
- 禁用表达要具体，尤其是恐吓、确定性预言、危险仪式、专业替代、第三方隐私侵犯。
- 真实对话衍生案例必须先通过 [匿名真实对话验证流程](../匿名真实对话验证流程.md)。

## 与工具链关系

1. `symbolic_depth_lookup`：选择解释层级。
2. `symbolic_case_library`：选择安全案例和禁用表达。
3. 领域工具：记录牌阵、卦象、盘式、空间事实、命理资料或仪式风险。
4. `mystic_output_lint`：检查最终草稿。
