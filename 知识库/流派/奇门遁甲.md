# 奇门遁甲

## 适用场景

奇门遁甲常用于局势分析、择时、行动方案比较。首版只建立字段和流程框架，不提供完整盘式算法。

## 核心概念

- 局：特定时间与规则下形成的盘式
- 九宫：承载门、星、神、干等信息
- 门、星、神、天干：用于构成象意判断
- 用神：根据问题选择关注对象
- 候选用神：按已标注用神、日干、时干、值符、值使和问题类型生成的可审计关注点
- 派别/盘式差异：置闰、拆补、茅山、飞盘、转盘等会影响节气边界、局数、九宫布列或解释来源；不能混作同一盘。

## 标准流程

1. 确认问题、时间、地点、时区。
2. 使用 `qimen_school_reference` 说明派别/盘式差异和混用风险。
3. 使用 `qimen_method_guard` 确认派别、起局方式、真太阳时策略和节气来源。
4. 若策略前提不完整，不生成盘式；改为补问或记录外部盘来源。
5. 使用 `qimen_chart_record` 记录盘式字段。
6. 使用 `qimen_focus_selector` 或人工等价规则标记候选用神和相关宫位。
7. 分析宫位组合与行动含义。
8. 输出倾向、限制和备选行动。
