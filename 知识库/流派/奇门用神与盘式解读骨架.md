# 奇门用神与盘式解读骨架

## 用途

本文件给 agent 提供奇门遁甲盘式解释的中层规则：先确认方法和盘式完整性，再选择候选用神，最后把门、星、神、干组合转成现实行动提示。

这里的规则是安全、可审计的咨询骨架，不是某一派别的完整断法。不同流派的用神选择可能不同，输出时必须保留方法限制。

## 用神选择原则

| 来源 | 适用情况 | 置信度 | 注意 |
| --- | --- | --- | --- |
| 用户/外部盘已标注用神 | 外部排盘或老师笔记已给出关注宫位 | 高 | 记录来源，不重新发明理由 |
| 日干 | 看求测者、自身状态、主观资源 | 中 | 不等于固定结论，需要结合宫内门星神干 |
| 时干 | 看当前事件、行动对象、触发点 | 中 | 项目、行动、当下局势常用作候选 |
| 值使门 | 看行动路径、事情门类和推进方式 | 中 | 需确认值使门字段来源 |
| 值符星 | 看局面主调、关键资源或主导力量 | 中 | 不单独下结论 |
| 生门 | 生计、资源、经营、增长条件 | 低 | 财务/投资问题仍不能替代专业判断 |
| 开门 | 机会、沟通、打开局面、外部入口 | 低 | 只作辅助线索 |
| 休门 | 休整、停留、路径、寻找线索 | 低 | 适合出行、寻找、休整类问题辅助观察 |

## 问题类型与候选重点

| 问题类型 | 优先候选 | 输出重点 | 避免 |
| --- | --- | --- | --- |
| 项目/工作 | 已标注用神、时干、值使门、开门 | 推进条件、阻滞点、下一步行动 | 替用户保证项目成败 |
| 关系 | 已标注用神、日干、时干 | 互动结构、边界、沟通节奏 | 确定断言对方想法 |
| 生意/经营 | 已标注用神、生门、开门、时干 | 客流、资源、执行条件 | 投资、借贷、赌博建议 |
| 出行/搬迁 | 已标注用神、开门、休门、时干 | 路径、准备、延迟和风险 | 忽略现实安全和交通信息 |
| 时机/节奏 | 已标注用神、时干、值使门 | 可观察信号、等待或推进条件 | 给绝对日期保证 |
| 失物 | 已标注用神、时干、休门 | 排查路径和线索整理 | 保证找回 |

## 盘式解释层级

1. 方法层：起局方法、派别、时间、地点、时区、真太阳时、节气来源。
2. 完整性层：九宫、阴阳遁、局数、值符、值使、日干、时干是否齐全。
3. 用神层：先读已标注用神，再读日干/时干/值符/值使相关宫位。
4. 宫位层：宫内门、星、神、天盘干、地盘干、八卦。
5. 关系层：用神宫与相关宫之间的象意关系，只作结构观察。
6. 现实映射层：把象意转成信息收集、沟通、等待、调整、撤退或低风险推进。
7. 限制层：说明派别、盘式完整性和现实专业问题边界。

## 输出骨架

```text
方法限制：
盘式完整性：
候选用神：
优先观察宫：
门星神干象意：
现实映射：
低风险行动：
不能判断的部分：
```

## 错误样例

| 错误 | 风险 | 改写 |
| --- | --- | --- |
| “开门在某宫，所以项目一定成功。” | 过度确定 | “开门可作为机会线索，但还要看资源、阻滞和现实反馈。” |
| “生门旺，可以贷款加仓。” | 财务替代 | “不做投资/借贷建议；可整理你需要核对的现金流和风险。” |
| “对方宫这样，说明他一定爱你。” | 替他人下定论 | “只能把对方相关宫作为互动可能性，重点回到你的边界和沟通。” |
| “缺派别也能直接断。” | 方法混用 | “派别和排盘前提不明时，只能做方法说明或请用户补盘。” |
