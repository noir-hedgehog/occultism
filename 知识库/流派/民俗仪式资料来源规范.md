# 民俗仪式资料来源规范

## 用途

本规范用于处理驱邪、净化、护身、搬家仪式、民俗禁忌等资料。目标是让 agent 能区分“文化材料”“个人经验”“商业改编”“宗教传统”和“安全建议”，避免把未验证说法包装成事实或通用传统。

## 来源分级

| 类型 | 标注 | 可用方式 | 不可用方式 |
| --- | --- | --- | --- |
| 地域民俗 | `regional_folk` | 写作某地/某群体流传说法，需说明地区和上下文 | 写成所有人都应遵守 |
| 宗教传统 | `religious_tradition` | 写作特定传统中的实践，提醒尊重语境 | 简化成通用驱邪步骤 |
| 现代身心实践 | `modern_wellness` | 写作现代象征性安定流程 | 声称能治疗疾病或消灾 |
| 商业新灵性 | `commercial_new_age` | 写作商业课程/现代改编说法 | 冒充古老传统或保证效果 |
| 个人经验 | `personal_preference` | 写作个人偏好或自我安定方式 | 推广成普遍规则 |
| 未知来源 | `unknown` | 只作为待核材料，不进入强结论 | 当作可靠传统 |

## 必填上下文

- 地区或社群：资料来自哪里，是否只是局部习俗。
- 时间和来源：口述、书籍、田野记录、网络文章、课程或个人经验。
- 实践条件：是否涉及火、烟、药物、刀具、血液、密闭空间、儿童、孕妇、宠物或老人。
- 解释边界：文化含义、心理安定、空间整理和现实安全要分开。

## 安全转译

| 原始说法 | 安全转译 |
| --- | --- |
| 烧纸、点香、蜡烛驱邪 | 改为开窗、清洁、开灯、无火香氛或音乐 |
| 喝符水、吃草药粉 | 改为常温饮水、记录感受；不摄入未知物 |
| 用血、刀、针立誓 | 改为写下担忧并撕掉/收好；不接触自伤 |
| 诅咒或压制他人 | 改为边界声明、停止联系、寻求现实支持 |
| 确认有鬼或被下咒 | 改为“你感到不安，我们先处理安全和安定感” |

## 输出要求

1. 先运行 `ritual_safety_check`。
2. 可先运行 `ritual_source_example_lookup` 查看同类来源的安全写法和缺失上下文。
3. 对资料运行 `ritual_source_guard`，标明来源类型和缺失字段。
4. 只在 Green/Yellow 风险下提供低风险象征性步骤。
5. Orange/Red 只给安全替代和现实支持，不给仪式步骤。
6. 不确认超自然因果，不保证效果，不替代医疗、法律、心理或安全支持。

## 推荐低风险流程

1. 通风并检查燃气、电路、霉菌、异味和动线。
2. 清洁一个区域，控制在 10-20 分钟。
3. 开灯、播放轻音乐或使用无火香氛。
4. 写下一句担忧和一句结束语。
5. 记录睡眠、情绪和空间变化；若恐惧升级，联系可信任的人或专业支持。
