# 易经 64 卦速查

本页提供 64 卦的索引级资料，用于 agent 在完成问题守门和起卦记录后快速定位卦名、上下卦结构和解释方向。这里不收录原典全文；卦义应结合问题、变爻、变卦和现实处境解释。

## 使用边界

- 只作为象征结构和反思提示，不作为确定预言。
- 不替代医疗、法律、财务、安全等专业判断。
- 若涉及变爻，使用 [易经384爻索引](易经384爻索引.md) 或 `yijing_line_lookup`；原典爻辞和传统注疏需另接可靠来源。
