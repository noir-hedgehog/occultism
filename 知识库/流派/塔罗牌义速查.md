## 小阿尔卡那生成规则

完整 56 张小牌由“花色主题 + 数字/宫廷主题”组合生成。例如“宝剑三” = 宝剑的思想/沟通主题 + 三的协作/初步成果主题；逆位则看三的分散/期待落差和宝剑能量阻滞。

### 花色主题

| 花色 | 元素 | 主题 | 行动提醒 |
| --- | --- | --- | --- |
| 权杖 | 火 | 行动、意志、创造力 | 把灵感拆成可执行的第一步 |
| 圣杯 | 水 | 情绪、关系、感受 | 辨认真实感受并温和表达 |
| 宝剑 | 风 | 思想、沟通、判断 | 澄清事实、语言和决策标准 |
| 星币 | 土 | 资源、身体、金钱、现实建设 | 把问题落到资源、时间和习惯上 |

### 数字与宫廷主题

| 等级 | 关键词 | 阴影/逆位提醒 |
| --- | --- | --- |
| 王牌 | 种子、机会、潜能 | 尚未落地、只停留在可能性 |
| 二 | 平衡、选择、互动 | 摇摆、僵持、回避决定 |
| 三 | 发展、协作、初步成果 | 分散、沟通不齐、期待落差 |
| 四 | 稳定、边界、结构 | 停滞、封闭、安全感过度 |
| 五 | 冲突、挑战、失衡 | 消耗、执拗、受困感 |
| 六 | 修复、过渡、互助 | 停留过去、不平等给予、依赖 |
| 七 | 评估、防守、选择压力 | 怀疑、拖延、过度防御 |
| 八 | 推进、练习、调整 | 机械重复、焦躁、过劳 |
| 九 | 成熟、临界、个人成果 | 孤立、守成、最后一关焦虑 |
| 十 | 完成、负荷、循环终点 | 过载、难以放手、责任堆积 |

| 国王 | 外在掌控、责任、领导 | 僵硬控制、权威压迫、脱离感受 |
