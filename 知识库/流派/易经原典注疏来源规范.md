# 易经原典注疏来源规范

## 目的

把易经回答中的“原典文本、传统注疏、现代译注、网络断语、师承经验”分层，避免把二手解释或短视频断语包装成《周易》原文。

## 来源层级

| 来源类型 | 工具值 | 可用方式 | 引用边界 |
| --- | --- | --- | --- |
| 经文/卦辞爻辞 | `jingwen` | 可作原典文本层 | 只短引，标注卦名/卦号、爻位或卦辞、版本/出处 |
| 十翼/传文 | `shiyi` | 可作传统解释层 | 说明是传文/解释，不等同卦爻原文 |
| 王弼注 | `wangbi` | 可作魏晋义理注疏参考 | 说明是某家解释，不写成唯一正统 |
| 程朱/宋明理学注疏 | `chengzhu` | 可作宋明义理解释参考 | 与象数、现代咨询语言分开 |
| 现代译注/白话转述 | `modern_translation` | 可概括解释方向 | 不直接照搬，标注作者/书名或来源 |
| 网络断语/短视频说法 | `internet_claim` | 只能作为待辨析说法 | 不作为原典或可靠注疏依据 |
| 师承/个人经验说法 | `personal_lineage` | 只能作为某传承或经验 | 不升格为通行原典结论 |

## 必须降级的表达

- 必有灾、大凶、必死、血光、家破、一定出事
- 必发财、保证发财、稳赚、暴富、财运大开
- 必病、会得病、不用看医生、停药、治病
- 控制他、让他回来、强迫复合、咒
- 唯一正解、只有这一派对、绝对正统、不用看上下文

## 建议输出写法

```text
来源层级：网络断语/短视频说法
能否作为依据：不能作为《周易》原典或可靠注疏
安全改写：把“必有灾”改成“这里可以提醒你检查现实风险和可控行动”
引用边界：若要引用原典，需补充卦名/爻位、原文出处和版本
```

## 工具命令

```bash
python3 agent-tools/scripts/yijing_source_reference_guard.py --text "短视频说这个爻必有灾、股票必发财" --source-type internet_claim
```
