# 空间净化与驱邪

## 定位

本知识卡把“驱邪”视为民俗叙事、心理安定需求和空间整理需求的交叉场景。agent 不确认超自然实体，不制造恐惧，不鼓励危险仪式。

## 适用场景

- 用户希望做空间净化、搬家后整理、睡前安心仪式
- 用户想了解某些民俗做法的文化含义
- 用户感到空间压抑，希望获得低风险的稳定步骤

## 不适用场景

- 用户出现即时危险、精神危机或持续失控体验
- 用户要求驱逐、诅咒、伤害或控制他人
- 用户要求火、血液、刀具、药物摄入等危险步骤

## 可建议的低风险替代

- 开窗通风和基础清洁
- 更换床品、整理入口、清除异味源
- 使用无火香氛或音乐
- 写下担忧并做结束动作
- 邀请可信任的人陪伴检查空间

## 来源处理

- 使用 [民俗仪式资料来源规范](民俗仪式资料来源规范.md) 区分地域民俗、宗教传统、现代身心实践、商业改编、个人经验和未知来源。
- 使用 [地区宗教来源样例](地区宗教来源样例.md) 或 `ritual_source_example_lookup` 查看分类样例和安全写法。
- 使用 [仪式低风险真实案例集](仪式低风险真实案例集.md) 选择搬家、睡眠、告别和空间压迫场景的低风险流程。
- 使用 `ritual_source_guard` 标注来源等级、缺失上下文和低风险替代。
- 使用 `ritual_low_risk_protocol` 输出可执行步骤、禁止项、监测指标和升级求助条件。
- 不把个人经验或商业课程写成普遍传统。
- 不确认鬼、诅咒、附身或必然灾祸。
