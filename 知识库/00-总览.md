# 总览

## 目标

建立一套玄学领域 agent 体系，支持：

- 识别用户请求属于哪类流派或服务场景
- 按流派调用对应 SOP 与知识卡
- 使用结构化工具收集信息、生成盘面/牌阵/卦象/空间检查项
- 输出可解释、低风险、可复盘的建议
- 为人类维护者提供知识库和看板

## 产物类型

| 类型 | 目录 | 作用 |
| --- | --- | --- |
| 知识卡 | `知识库/流派` | 给人和 agent 都能读的流派概要、术语、流程 |
| SOP | `知识库/SOP` | 明确何时问什么、如何判断风险、如何输出 |
| Tool 规格 | `agent-tools` | 定义可程序化的输入、输出、校验、审计字段 |
| Skill 蓝图 | `codex-skills` | 定义 agent 何时触发、读取哪些参考、按什么流程工作 |
| 看板 | `知识库/看板.md` | 跟踪研究、实现、验证、发布 |

## 深度解释层

- [流派/跨流派深度解读矩阵.md](流派/跨流派深度解读矩阵.md)：把牌义、卦义、盘式、方位、命理术语和仪式请求统一成解释步骤、边界和案例。

## 成熟度

| 等级 | 标准 |
| --- | --- |
| L0 草稿 | 有范围和风险边界，但缺少完整流程 |
| L1 可读 | 有知识卡、基础术语、禁区和输出格式 |
| L2 可执行 | 有 SOP、示例输入输出、tool schema |
| L3 可验证 | 有案例集、测试清单、错误样例和质量标准 |
| L4 可发布 | 有 Codex Skill、稳定工具、维护责任人和版本记录 |

## 首批服务场景

- 塔罗象征解读：情绪梳理、选择对照、关系/工作反思
- 风水空间审视：居家/办公动线、采光、收纳、心理舒适度与传统形法语言
- 易经/周易类占问：问题澄清、卦象生成记录、卦辞爻辞解释框架
- 六爻占问：六亲、六神、世应、用神和爻位的安全解释框架
- 奇门遁甲类择时/局势分析：信息收集、盘式记录、象意归纳
- 空间净化/驱邪安全咨询：风险筛查、低风险文化仪式、现实支持转介
