# Aura Chakra Symbolic Consultation

## Use When

- The user asks about 气场, 气场颜色, 脉轮, 七轮, 能量场, 能量感受, 灵气, reiki, aura, or chakra.
- The user wants cultural learning, meditation/body-sensation records, or low-risk symbolic reflection.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `aura_chakra_request_guard`.
3. If blocked, pause aura/chakra consultation and reframe to medical, mental-health, safety, privacy, budget, relationship-boundary, or grounding support.
4. If allowed, run `aura_chakra_sensation_recorder`.
5. Run `aura_chakra_symbol_lookup` for known centers, colors, or sensations.
6. Run `aura_chakra_reflection_planner`.
7. Draft with symbolic, body-awareness, and possibility language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/aura_chakra_request_guard.py`
- `agent-tools/scripts/aura_chakra_sensation_recorder.py`
- `agent-tools/scripts/aura_chakra_symbol_lookup.py`
- `agent-tools/scripts/aura_chakra_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: aura/chakra symbols are cultural/body-awareness prompts, not diagnosis, healing proof, spirit proof, identity rank, or predictions.
- Context summary: centers, colors, sensations, duration, intensity, context, grounding notes, and focus.
- Symbol layer: center/color/sensation prompts with cautious combination notes.
- Reality layer: physical symptoms, mental-health signals, safety, budget, privacy, and relationship constraints first.
- Action layer: low-cost, reversible, non-harmful grounding or journaling steps.

## Hard Stops

- Medical treatment, diagnosis, medication replacement, severe insomnia, panic, chest pain, breathing difficulty, hallucinations, pregnancy, surgery, or crisis claims.
- Spirit possession, curse, energy attack, exorcism confirmation, remote clearing necessity, or supernatural proof.
- Deterministic identity labels, soul rank, low-frequency labels, karma accusations, or personality judgments.
- Gambling, investment, loans, lottery, wealth guarantees, relationship guarantees, or fate certainty.
- Third-party mind reading, privacy invasion, coercion, revenge, forced reunion, expensive healing pressure, or repeated dependency.
