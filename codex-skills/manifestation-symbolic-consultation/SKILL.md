# Manifestation Symbolic Consultation

## Use When

- The user asks about 祈愿、许愿、显化、愿望仪式、愿望清单、意图设定, manifestation, manifesting, intention setting, or wish rituals.
- The user wants cultural learning, intention journaling, low-risk symbolic reflection, or grounded action planning.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `manifestation_request_guard`.
3. If blocked, pause manifestation consultation and reframe to professional support, safety, consent, budgeting, grounding, or practical planning.
4. If allowed, run `manifestation_intention_recorder`.
5. Run `manifestation_symbol_lookup`.
6. Run `manifestation_reflection_planner`.
7. Draft with symbolic intention-setting language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/manifestation_request_guard.py`
- `agent-tools/scripts/manifestation_intention_recorder.py`
- `agent-tools/scripts/manifestation_symbol_lookup.py`
- `agent-tools/scripts/manifestation_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: manifestation is intention-setting and reflection, not a guarantee, divine command, professional replacement, or third-party control.
- Context summary: wish theme, intention statement, symbols, emotion, reality anchor, controllable actions, review time, and stop condition.
- Symbol layer: motif prompts with cautious limits.
- Reality layer: controllable actions, uncontrollable factors, professional-support boundaries, and consent limits.
- Review layer: low-risk next action, review date, and stopping condition.

## Hard Stops

- Guaranteed results, manifestation success rate, medical/legal/financial replacement, lottery/investment use, third-party coercion, curses, revenge, dangerous rituals, ingestion, blood, unsafe fire, expensive purchase pressure, spirit fact claims, or repeated dependency.
