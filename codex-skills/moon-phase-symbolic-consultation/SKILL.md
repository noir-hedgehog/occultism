# Moon Phase Symbolic Consultation

## Use When

- The user asks about 月相、月亮周期、新月、满月、上弦月、下弦月、月食、蓝月、超级月亮、新月许愿、满月释放、月亮仪式, moon phase, new moon, full moon, or lunar-cycle themes.
- The user wants cultural learning, cycle journaling, intention setting, or low-risk review.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `moon_phase_request_guard`.
3. If blocked, pause moon-phase consultation and reframe to medical, fertility, mental-health, safety, privacy, budget, relationship-boundary, or grounding support.
4. If allowed, run `moon_phase_context_recorder`.
5. Run `moon_phase_symbol_lookup` for known phases or lunar events.
6. Run `moon_phase_reflection_planner`.
7. Draft with symbolic cycle-reflection and present-action language only, then run or emulate `mystic_output_lint`.

## Output Shape

- Boundary statement: moon phases are cycle metaphors, not manifestation guarantees, astronomical authority, predictions, or professional advice.
- Context summary: phase, date/source notes, themes, intentions, practical constraints, and focus.
- Symbol layer: phase prompts with cautious limits.
- Reality layer: current constraints, schedule, safety, budget, privacy, and professional-support limits.
- Action layer: low-cost, no-fire, reversible journaling, review, rest, planning, or communication steps.

## Hard Stops

- Medical treatment, diagnosis, medication replacement, fertility or pregnancy claims, severe insomnia, panic, hallucinations, or crisis claims.
- Fire, burning paper/photos/hair, blood, fasting, sleep deprivation, dangerous locations, curse work, or revenge rituals.
- Guaranteed manifestation, wealth, lottery, investment, gambling, loans, relationship guarantees, or fate certainty.
- Third-party mind reading, privacy invasion, coercion, forced reunion, cutting off a third party, expensive course pressure, or repeated dependency.
