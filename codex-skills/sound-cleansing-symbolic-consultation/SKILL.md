# Sound Cleansing Symbolic Consultation

## Use When

- The user asks about 声响净化、声音净化、铃钵、颂钵、铃铛、音叉、拍手净化、诵念, mantra, chanting, singing bowl, or sound cleansing.
- The user wants symbolic space-reset, attention, grounding, low-risk practice planning, or cultural explanation.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `sound_cleansing_request_guard`.
3. If blocked, pause sound-cleansing interpretation and reframe to low-risk space reset, sensory safety, qualified professional support, or grounded action.
4. If allowed, run `sound_cleansing_context_recorder`.
5. Run `sound_cleansing_symbol_lookup`.
6. Run `sound_cleansing_practice_planner`.
7. Draft with symbolic space-reset, attention, grounding, and review language only, then run or emulate `mystic_output_lint`.

- `agent-tools/scripts/mystic_intake_triage.py`

- `agent-tools/scripts/sound_cleansing_context_recorder.py`

- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: sound-cleansing language is symbolic space reset, not a promise of exorcism, healing, sleep, luck changes, or supernatural effects.
- Context summary: space, timing, sound tools, intention, volume/duration, body sensations, neighbor/pet/infant boundaries, review time, and stop condition.
- Symbol layer: bell, bowl, tuning fork, clap, mantra, silence, window, and timer motifs with cautious prompts.
- Practice layer: short, low-volume, reversible steps with start, observation, optional sound, quiet close, and grounded action.
- Review layer: review time and stop condition to avoid repeated cleansing, paid tool loops, or sensory overwhelm.

## Hard Stops

- Medical or mental-health replacement, coercive exorcism claims, unsafe sound exposure, neighbor/legal conflict, guaranteed effects, expensive tool pressure, or repeated dependency.
