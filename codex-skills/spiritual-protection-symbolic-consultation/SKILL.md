# Spiritual Protection Symbolic Consultation

## Use When

- The user asks about 恶眼、能量防护、灵性防护、能量断联、保护罩、防小人、负能量, evil eye, cord cutting, energy protection, or energy cords.
- The user wants symbolic boundary reflection, grounding, reminder-object use, or low-risk safety planning.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `spiritual_protection_request_guard`.
3. If blocked, pause protection interpretation and reframe to reality safety, boundaries, trusted support, emergency help, or professional support.
4. If allowed, run `spiritual_protection_context_recorder`.
5. Run `spiritual_protection_symbol_lookup`.
6. Run `spiritual_protection_reflection_planner`.
7. Draft with symbolic boundary-reflection language only, then run or emulate `mystic_output_lint`.

- `agent-tools/scripts/mystic_intake_triage.py`

- `agent-tools/scripts/spiritual_protection_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: protection language is symbolic boundary reflection, not proof of harm, curses, surveillance, spirits, or third-party intent.
- Context summary: protection focus, trigger context, sensations, emotions, reality safety context, boundary actions, symbolic items, review time, and stop condition.
- Symbol layer: evil-eye/protection/cord-cutting motifs with cautious prompts.
- Action layer: practical boundaries, support contacts, notification/privacy settings, grounding, and low-cost reminder-object use.
- Review layer: review time and stopping condition to avoid repeated checking or fear loops.

## Hard Stops

- Persecution confirmation, identifying who harmed the user, curse/retaliation, dangerous rituals, stalking/surveillance, professional or safety replacement, coercive relationship control, expensive remedial purchases, or repeated dependency.
