# Animal Omen Symbolic Consultation

## Use When

- The user asks about 动物征兆, 动物预兆, 鸟兽虫鱼, 鸟进屋, 鸟撞窗, 乌鸦叫, 猫头鹰叫, 蛇进屋, 蜘蛛, 蝴蝶, 飞蛾, animal omen, bird omen, or insect omen.
- The user has an animal observation to record, wants cultural learning, or wants low-risk symbolic reflection.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `animal_omen_request_guard`.
3. If blocked, pause animal-omen consultation and reframe to real-world safety, public health, animal rescue, veterinary, property, emergency, privacy, or emotional support.
4. If allowed, run `animal_omen_observation_recorder`.
5. Run `animal_omen_symbol_lookup` for known animals, birds, insects, or motifs.
6. Run `animal_omen_interpretation_planner`.
7. Draft with cultural, symbolic, and possibility language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/animal_omen_request_guard.py`
- `agent-tools/scripts/animal_omen_observation_recorder.py`
- `agent-tools/scripts/animal_omen_symbol_lookup.py`
- `agent-tools/scripts/animal_omen_interpretation_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: animal omens are cultural/symbolic prompts, not facts, disaster warnings, spirit messages, or safety instructions.
- Observation summary: animal, behavior, location, timing, frequency, source, and safety context.
- Symbol layer: animal-by-animal prompts with cautious cultural and personal-reflection notes.
- Reality layer: bite, pest, wildlife, injured animal, public health, property, rescue, and professional-support constraints first.
- Action layer: low-cost, reversible, non-harmful observation, safety, or reflection steps.

## Hard Stops

- Animal harm, capturing, poisoning, burning, blood sacrifice, ritualized animal use, or unsafe handling.
- Bite/scratch, bat/snake contact, wasp nest, rodent infestation, pest control, contagious disease, parasite, or public-health replacement.
- Deterministic death, disaster, curse, spirit possession, exorcism confirmation, or supernatural proof.
- Gambling, investment, loans, lottery, wealth guarantees, relationship guarantees, or fate certainty.
- Third-party mind reading, privacy invasion, coercion, revenge, forced reunion, or repeated dependency.
