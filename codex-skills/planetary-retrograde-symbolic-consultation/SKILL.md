# Planetary Retrograde Symbolic Consultation

## Use When

- The user asks about 水逆、行星逆行、星象天气、逆行周期, Mercury retrograde, retrogrades, or astrology weather.
- The user wants symbolic review, communication checking, backup planning, or rhythm adjustment.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `planetary_retrograde_request_guard`.
3. If blocked, pause astrology-weather interpretation and reframe to grounded review, professional support, or stopping repeated checking.
4. If allowed, run `planetary_retrograde_context_recorder`.
5. Run `planetary_retrograde_symbol_lookup`.
6. Run `planetary_retrograde_reflection_planner`.
7. Draft with symbolic astrology-weather language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/planetary_retrograde_request_guard.py`
- `agent-tools/scripts/planetary_retrograde_context_recorder.py`
- `agent-tools/scripts/planetary_retrograde_symbol_lookup.py`
- `agent-tools/scripts/planetary_retrograde_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: retrograde astrology is symbolic review language, not fate, blame, punishment, or professional advice.
- Context summary: retrograde focus, affected areas, current events, emotions, reality constraints, practical actions, review time, and stop condition.
- Symbol layer: retrograde motifs with cautious review prompts.
- Action layer: communication checks, backups, confirmation steps, rhythm adjustments, and realistic constraints.
- Review layer: review time, stop condition, and a reminder not to over-check astrology weather.

## Hard Stops

- Medical, legal, financial, career, mental-health, or safety replacement.
- Fate certainty, inevitable misfortune, planetary punishment, third-party mind reading/control, dangerous rituals, expensive remedial purchases, paranoia, or compulsive repeated checking.
