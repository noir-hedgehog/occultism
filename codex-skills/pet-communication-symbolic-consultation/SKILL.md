# Pet Communication Symbolic Consultation

## Use When

- The user asks about 宠物沟通、动物沟通、宠物灵性讯息、亡宠怀念, pet communication, animal communication, or animal-spirit messages.
- The user wants symbolic writing, behavior observation, care planning, or grief support.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `pet_communication_request_guard`.
3. If blocked, pause pet communication and reframe to veterinary care, missing-pet search, privacy, grief support, or grounded observation.
4. If allowed, run `pet_communication_context_recorder`.
5. Run `pet_communication_symbol_lookup`.
6. Run `pet_communication_reflection_planner`.
7. Draft with symbolic pet-observation language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/pet_communication_request_guard.py`
- `agent-tools/scripts/pet_communication_context_recorder.py`
- `agent-tools/scripts/pet_communication_symbol_lookup.py`
- `agent-tools/scripts/pet_communication_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: pet communication is symbolic writing and observation, not veterinary diagnosis, factual message translation, spirit proof, or missing-pet location.
- Context summary: pet type, relationship, observations, time context, health/vet boundary, emotions, care actions, and reality anchor.
- Symbol layer: behavior or memory motifs with cautious limits.
- Care layer: practical care, observation, vet boundary, missing-pet search boundary, or grief support.
- Review layer: low-risk next action, observation window, and stopping condition.

## Hard Stops

- Veterinary emergency or replacement, medication guidance, missing-pet location claims, guaranteed true pet messages, deceased-pet spirit facts, third-party blame, revenge, expensive purchase pressure, or repeated dependency.
