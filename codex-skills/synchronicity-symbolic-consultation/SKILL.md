# Synchronicity Symbolic Consultation

## Use When

- The user asks about 同步性、天使数字、重复数字、重复征兆、宇宙讯号、1111、11:11, synchronicity, angel numbers, or repeating signs.
- The user wants symbolic journaling, pattern recording, emotional reflection, or low-risk action planning.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `synchronicity_request_guard`.
3. If blocked, pause synchronicity interpretation and reframe to safety, grounded tracking, professional support, or stopping repeated checking.
4. If allowed, run `synchronicity_event_recorder`.
5. Run `synchronicity_symbol_lookup`.
6. Run `synchronicity_reflection_planner`.
7. Draft with symbolic journaling language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`
- `agent-tools/scripts/synchronicity_request_guard.py`
- `agent-tools/scripts/synchronicity_event_recorder.py`
- `agent-tools/scripts/synchronicity_symbol_lookup.py`
- `agent-tools/scripts/synchronicity_reflection_planner.py`
- `agent-tools/scripts/mystic_output_lint.py`

## Output Shape

- Boundary statement: synchronicity is symbolic recording and reflection, not a command, prediction, spirit fact, professional decision system, or mind-reading proof.
- Event summary: repeated signs, frequency, situation, emotions, reality anchor, practical actions, and stop condition.
- Symbol layer: number/sign motifs with cautious personal-reflection prompts.
- Action layer: 1-3 low-risk actions grounded in the user's real context.
- Review layer: stop condition, review time, and a reminder not to search in unsafe contexts.

## Hard Stops

- Dangerous sign checking while driving, crossing roads, or in unsafe settings.
- Cosmic/angel/spirit commands, fate certainty, future guarantees, or supernatural proof.
- Financial, professional, medical, legal, or mental-health replacement.
- Third-party mind reading, privacy claims, expensive decoding pressure, or compulsive repeated checking.
