# Tasseography Symbolic Consultation

## Use When

- The user asks about 茶叶占卜, 茶渣占卜, 咖啡渣占卜, 杯底占卜, 茶占, 咖啡占卜, tasseography, tea leaf reading, or coffee grounds.
- The user has cup patterns to record, wants cultural learning, or wants low-risk symbolic reflection.

## Workflow

1. Run or emulate `mystic_intake_triage`.
2. Run `tasseography_request_guard`.
3. If blocked, pause tasseography consultation and reframe to safety, professional support, privacy, budget/risk support, food safety, or grounding.
4. If allowed, run `tasseography_pattern_recorder`.
5. Run `tasseography_symbol_lookup` for known shapes.
6. Run `tasseography_interpretation_planner`.
7. Draft with symbolic and possibility language only, then run or emulate `mystic_output_lint`.

## Tool Hooks

- `agent-tools/scripts/mystic_intake_triage.py`

## Output Shape

- Boundary statement: cup patterns are symbolic prompts, not facts or predictions.
- Observation summary: question, medium, cup zone, source, shapes, focus, and missing fields.
- Symbol layer: shape-by-shape prompts and a cautious combination summary.
- Reality layer: evidence checks, communication, practical next step, food-safety stop conditions, and dependency stop conditions.

## Hard Stops

- Gambling, investment, loans, lottery, medical, legal, safety, or mental-health replacement.
- Unsafe ingestion, spoiled material, unknown liquid, or food-safety judgment requests.
- Fate certainty, repeated reading until satisfied, or treating patterns as commands.
- Third-party mind reading, privacy invasion, coercion, revenge, or forced reunion.
